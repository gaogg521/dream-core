# ONNX Runtime shared libraries shipped next to `dreamcore` (loaded at run time,
# see crates/dream-domain-devops/src/onnxruntime.rs).
#
# Production must not depend on one code-hosting URL. The upstream
# microsoft/onnxruntime GitHub repository went away on 2026-11-20 (every release
# URL 404'd and two release builds failed), so GitHub release archives are NOT
# used any more. Each target lists its sources in order; the first one that
# downloads AND matches its sha256 is used (scripts/fetch-onnxruntime.*):
#
#   <rust-target> <url> <sha256>
#
#  1. Our own COS mirror (onework-1521070673/build-deps/onnxruntime/<version>/...):
#     the exact libraries we build and test with. Raw files, write-once.
#  2. The official `onnxruntime` wheel of the same version on PyPI (a zip carrying
#     the same CPU build under onnxruntime/capi/), verified against the same
#     sha256 as the mirror's source wheel.
#
# Version 1.29.0 (since 2026-11-20). 1.28.3, which dreamcore <= v0.1.105 and the
# 1.0.17 / 1.0.18 enterprise images ship, was only ever published on GitHub; it
# stays mirrored in COS (build-deps/onnxruntime/1.28.3/...). To go back to it,
# swap the two lines of each target for the commented ones below.
# The `ort` crate (2.0.0-rc.13) is written for ONNX Runtime 1.28; 1.29.0 passes
# `local_embedding_fresh_install` on Windows, but the enterprise image build and
# the other platforms are what validated (or will validate) it for real.
#
# Mirror files are write-once: never replace an object under a version directory,
# add a new version directory and a new pin instead (the sha256 is of those bytes).
#
# x86_64-apple-darwin is deliberately absent: no Intel Mac build is published,
# so local embedding is unavailable there (the program reports it; a remote
# embedding endpoint still works).
#
# Bumping: take url + sha256 from https://pypi.org/pypi/onnxruntime/<version>/json
# (urls[].url / .digests.sha256) for the four platforms, extract the library from
# each wheel, upload it to a NEW COS directory, add the lines here, then run
# scripts/fetch-onnxruntime.* once per platform and the embedding acceptance test:
#   ORT_DYLIB_PATH=<library> cargo test -p dream-domain-devops #     --test local_embedding_fresh_install -- --ignored
