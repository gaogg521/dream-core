# 知识库正文保存与默认向量索引

更新日期：2026-10-14。实现位于 crates/dream-domain-devops。

## 接口行为

- 文档登记继续支持 personal、org、team 的既有权限策略，个人文档仅本人可见。
- GET /api/one/devops/rag/documents/{id}/content 按文档可见性检查，允许已授权只读成员阅读；PUT 仍检查写权限。
- PUT 正文请求上限 16 MB，保存时置为 pending 并清除旧错误；非空正文保存后异步排队处理，响应无需等待嵌入完成。
- 后台任务等待 500 ms 后进入串行队列，失败最多尝试三次。日志只记录文档 ID 和尝试次数，不记录正文。
- Markdown 内嵌图片的 base64 数据不会作为正文进行向量切片；嵌入完成后检查正文是否仍与任务输入一致，过期输入不写回片段。
- 列表文字搜索覆盖已保存标题和正文，并沿用既有可见性过滤。

## 嵌入配置

优先级为管理员保存的有效配置、部署环境中的有效配置、本地默认模型。明确提供了不完整的环境覆盖仍视为配置错误。

本地默认端点为 local://embedding，模型为 paraphrase-multilingual-MiniLM-L12-v2 的量化 ONNX 版本；推理在阻塞线程池中执行，复用串行模型实例。首次初始化下载模型，后续使用缓存；缓存路径依次基于 ONE_DATA_DIR、LOCALAPPDATA/OneWork、HOME/.cache/onework，最后回退临时目录，其下为 models/embedding。

本地推理无需外部嵌入服务；首次下载、缓存离线加载、企业平台构建与离线分发须分别验证，不可由 Windows DEV 成功推断全部平台可用。

## 验收与限制

本次开发库单元测试 193 项通过。实际 Electron DEV 使用更新后的内置二进制，健康检查及本地默认配置读取成功；PDF 提取 1803 字、personal 登记、正文回读、自动生成 3 个片段通过。三份测试文档自动处理后，差旅同义问题的相似度高于会议室干扰文档。

后台任务为进程内队列，不是持久化作业系统。重启不会自动回填所有历史 pending/error 文档；需重新保存或手动处理。完全离线加载、跨平台企业镜像、桌面所有交互仍未完成全量验收。本次没有发布安装包、镜像或离线包。


## 原文件阅读与内置学习指南（2026-10-14 补充）

原文件与检索正文分开保存。新增原文件上传/下载接口 `/api/one/devops/rag/documents/{id}/source`，沿用文档读写权限；文件存放在数据目录下的 `knowledge-sources`，不暴露本机路径。单个原文件上限 100 MiB，支持单段 Range 请求。

个人端导入保留原文件，阅读页依据文件类型显示 PDF、图片、音视频或隔离 HTML；不支持的格式提供原文件下载。旧的纯提取文本资料可补充原文件。PDF 阅读已在个人 WebUI 实测原始页面、缩略图、页码和缩放；企业后端本轮接口尚需更新后再做原文件联动验收。Office/设计文件在线编辑尚未实现。

个人端和企业端内置两篇原创教程：《一分钟上手资料库》《资料库使用指南》。首页卡片和目录中的学习入口均可页内打开，正文提供中文和英文。教程不自动创建用户文档，不占用个人资料列表和搜索结果。

完整差距与实测边界见 `docs/knowledge-library-product-gaps.zh-CN.md`。自动保存不等于版本历史，静态 HTML 预览不等于数据工作台。
