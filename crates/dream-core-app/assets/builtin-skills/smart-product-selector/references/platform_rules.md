# 主流电商平台规则速查

> 最后更新：2026-09-08 | 费率可能随平台政策调整，请以官方最新公告为准

## 一、国内电商平台

### 1.1 淘宝/天猫

| 项目 | 淘宝C店 | 天猫 |
|------|---------|------|
| 保证金 | ¥1000-5000（品类不同） | ¥50000-150000 |
| 佣金（技术服务费） | 0% | 0.5-5%（品类不同） |
| 推广工具 | 直通车/万相台/超级推荐 | 同左 |
| 推广费占比 | 售价 10-30% | 售价 10-25% |
| 结算周期 | 买家确认收货后 | T+15（含售后期） |
| 退货率参考 | 服装 30-40%，标品 5-15% | 略低于C店 |

**热门品类佣金率：**
- 服饰鞋包：2-5%
- 美妆个护：2-5%
- 食品：1-3%
- 3C数码：1-2%
- 家居日用：2-5%
- 母婴：2-4%

### 1.2 京东

| 项目 | POP商家（第三方） | 京东自营 |
|------|-------------------|---------|
| 保证金 | ¥5000-50000 | 无（供应商模式） |
| 佣金 | 3-8%（品类不同） | 采购价结算 |
| 推广工具 | 京准通/快车/海投 | 平台运营 |
| 结算周期 | T+15 | 月结30-60天 |
| 退货率参考 | 标品 5-10%，服装 20-30% | 略高 |

**京东优势品类：** 3C数码、家电、图书、家居、母婴

### 1.3 抖音电商

| 项目 | 说明 |
|------|------|
| 保证金 | ¥2000-20000（品类不同） |
| 技术服务费 | 1-5%（品类不同） |
| 达人佣金 | 10-30%（如走达人分销） |
| 推广工具 | 千川投流 |
| 推广费占比 | 售价 15-40%（直播场景偏高） |
| 结算周期 | T+7（普通）/ T+15（部分品类） |
| 退货率参考 | 直播 30-50%，商城 10-20% |

**抖音特点：**
- 内容驱动，短视频/直播是核心流量入口
- 退货率偏高（冲动消费），服装类目尤甚
- 爆款逻辑强，单品起量快但生命周期短
- 适合高毛利、强视觉冲击力、易展示的产品

### 1.4 拼多多

| 项目 | 说明 |
|------|------|
| 保证金 | ¥1000-10000 |
| 佣金 | 0.6-3%（基础技术服务费） |
| 推广工具 | 多多搜索/多多场景/全站推广 |

**拼多多特点：**

- 适合工厂直供/产业带白牌
- 百亿补贴频道流量大但利润薄
- 适合走量型标品、日用品、农产品

## 四、选品红线（务必规避）

- 侵权/仿牌（商标/外观/专利侵权）
- 违禁品（管制刀具、枪械配件、毒品相关）
- 无资质高风险品（医疗器械、保健品、婴幼儿食品）
- 季节性过强且无库存消化渠道的品类
- 被平台限流/管控的擦边品类
