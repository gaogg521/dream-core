# 选品评估指标框架

## 一、市场容量评估

### 1.1 核心指标

| 指标 | 数据源 | 说明 |
|------|--------|------|
| 月搜索量 | 百度指数/微信指数/生意参谋 | 反映消费者主动需求强度 |
| 月销量 TOP10 均值 | 平台前台抓取 | 反映实际成交规模 |
| 品类 GMV 估算 | 行业报告/第三方数据 | 整体市场盘子 |
| 搜索/成交比 | 搜索量 ÷ 成交量 | < 5 说明转化好，> 15 说明只看不买 |

### 1.2 评分标准（1-5分）

| 得分 | 月销规模 | 搜索量级 |
|------|---------|---------|
| 5 | > 10万单/月 | 指数 > 10000 |
| 4 | 5-10万单/月 | 指数 5000-10000 |
| 3 | 1-5万单/月 | 指数 1000-5000 |
| 2 | 1000-1万单/月 | 指数 100-1000 |
| 1 | < 1000单/月 | 指数 < 100 |

## 二、增长趋势评估

### 2.1 判断维度

- **搜索趋势**：近12个月搜索量变化曲线
- **销量趋势**：头部商品销量月度变化
- **新品占比**：近6个月上新商品占总在售比例（> 30% 为活跃市场）
- **社交热度**：小红书/抖音相关笔记/视频增速

### 2.2 生命周期判断

| 阶段 | 搜索 YoY | 新品占比 | 价格趋势 |
|------|----------|---------|---------|
| 导入期 | > 100% | > 50% | 试探性定价，波动大 |
| 上升期 | 30-100% | 30-50% | 稳中有升 |
| 成熟期 | 0-30% | 10-30% | 稳定，促销频繁 |
| 衰退期 | < 0% | < 10% | 持续走低，清仓多 |

## 三、竞争格局评估

### 3.1 集中度指标

- **CR3**（前三名市占率）：< 30% 分散 / 30-60% 中等 / > 60% 垄断
- **CR5**（前五名市占率）：同上比例
- **HHI指数**：各商家市占率平方和。> 2500 高度集中，1500-2500 中等，< 1500 分散

### 3.2 壁垒评估

| 壁垒类型 | 判断标准 | 难度 |
|---------|---------|------|
| 品牌壁垒 | TOP10 中品牌店占比 > 50% | 高 |
| 评价壁垒 | TOP10 平均评价数 > 5万 | 高 |
| 价格壁垒 | 头部价格 < ¥20，利薄 | 中高 |
| 资质壁垒 | 需要3C/食品/医疗等资质 | 视品类 |
| 供应链壁垒 | 核心原料/工艺被少数厂家控制 | 中高 |
| 资金壁垒 | 首批备货 > 10万 | 中 |

### 3.3 评分标准（1-5分，5=最容易进入）

| 得分 | 竞争状态 |
|------|---------|
| 5 | CR3 < 20%，无品牌垄断，无资质要求 |
| 4 | CR3 20-30%，有白牌空间，门槛低 |
| 3 | CR3 30-50%，需差异化定位 |
| 2 | CR3 50-70%，品牌强势，新进入者空间小 |
| 1 | CR3 > 70%，高度垄断或需要高投入 |

## 四、利润空间评估

### 4.1 成本结构拆解

```
终端售价 = 采购成本 + 物流 + 包材 + 平台佣金 + 推广费 + 售后损耗 + 毛利
```

典型费率参考（详见 platform_rules.md）：
- 平台佣金：1-10%（品类差异大）
- 推广费：售价的 10-30%
- 售后/退换：售价的 3-8%
- 物流：视重量，一般 3-8 元/单

### 4.2 评分标准（1-5分）

| 得分 | 毛利率 | 单件净利 |
|------|--------|---------|
| 5 | > 60% | > ¥50 |
| 4 | 45-60% | ¥30-50 |
| 3 | 30-45% | ¥15-30 |
| 2 | 15-30% | ¥5-15 |
| 1 | < 15% | < ¥5 |

## 五、供应链评估

### 5.1 评估维度

| 维度 | 评估要点 |
|------|---------|
| 货源丰富度 | 1688 搜索结果数量，> 500 家为丰富 |
| 起定量 | MOQ 是否匹配预算，< 100 件友好 |
| 品控难度 | 标准化品容易，定制品/生鲜/易碎品难度大 |
| 产地集中度 | 是否有明确产业带，便于验货 |
| 交期 | 常规 < 7 天可接受 |

### 5.2 评分标准（1-5分，5=最容易）

| 得分 | 供应链状态 |
|------|-----------|
| 5 | 1688 > 500家，MOQ < 50，标品无需验货 |
| 4 | 1688 200-500家，MOQ < 100，品控简单 |
| 3 | 1688 50-200家，MOQ < 500，需基本质检 |
| 2 | 1688 < 50家，MOQ > 500，品控较复杂 |
| 1 | 货源稀缺/需定制/进口/特殊资质 |

## 六、综合评分公式

```
综合得分 = 市场容量(0.30) + 增长趋势(0.20) + 竞争可进入性(0.25)
         + 利润空间(0.30) + 供应链难度(0.15)

满分 5.0 分
```

### 决策矩阵

| 得分区间 | 决策 | 行动建议 |
|---------|------|---------|
| 4.0 - 5.0 | 强烈推荐 | 立即着手选品入场，抢占窗口 |
| 3.0 - 3.9 | 值得尝试 | 找准差异化切入点，小批量测试 |
| 2.0 - 2.9 | 谨慎考虑 | 需明确独特优势，否则不推荐 |
| < 2.0 | 建议放弃 | 风险大于收益，寻找其他方向 |

## 七、风险评估清单

每个推荐品类必须评估：

- [ ] 政策合规风险（资质/认证/禁售）
- [ ] 季节性波动风险（淡旺季差异 > 50%）
- [ ] 价格战风险（同质化程度）
- [ ] 库存积压风险（保质期/潮流周期）
- [ ] 供应链断裂风险（单一供应商依赖）
- [ ] 平台规则变动风险（佣金调整/流量分配变化）
