# 诗词查询与赏析

## 一、四类查询场景

### 1. 查诗补全（给上句/下句/残句）
- 用户给残句 → 依据公共版权古籍常识补全 → 输出全句 + 篇名 + 作者。
- 示例：「'落霞与孤鹜齐飞'下一句」→ 「秋水共长天一色」《滕王阁序》王勃。

### 2. 查出处
- 用户背得出诗句记不得出处 → 依据常识溯源 → 输出出处（篇名/作者/朝代）。
- 示例：「'人生自古谁无死'谁写的？」→ 文天祥《过零丁洋》。

### 3. 赏析
- 用户要某诗赏析 → 默诵/回忆原文 → 输出：原文 + 大意 + 名句点评 + 写作背景（简）。

### 4. 按主题找诗
- 用户给主题/情感（思乡/送别/励志/闲适/咏物）→ 按主题词联想经典篇目 → 输出 2-3 首选例 + 出处 + 一句赏析。

## 三、输出格式（赏析型）
```
【诗句】
（原文）

【出处】
《篇名》· 作者（朝代）

【大意】
（白话释义）

【简析】
（1-2句点评，点出情感/手法/名句价值）
```

## 四、易错点
1. **作者朝代别搞混**：同姓诗人多（李白/李商隐/李贺），作答时带朝代。
2. **篇名要全**：简称（如"滕王阁"）可能对应多篇，用全名"滕王阁序"。
3. **不编造赏析**：赏析基于原文可考内容，不随意发挥杜撰；记不清时如实说明"建议核对权威版本"。
