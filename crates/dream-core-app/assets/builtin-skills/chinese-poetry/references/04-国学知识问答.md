# 国学知识问答

## 一、四类问答场景

### 1. 典籍背景
- 例：「《资治通鉴》讲什么？」→ 依据常识作答 → 简介（编年体通史/司马光主编/起战国迄五代）。

### 2. 作者生平
- 问诗人/思想家生平 → 依据常识输出生平要点 + 代表作。

### 3. 典故解释
- 问成语/典故出处 → 依据常识输出原典出处 + 故事梗概 + 今义。
- 例：「'卧薪尝胆'出自哪？」→ 《史记·越王勾践世家》。

### 4. 文言翻译
- 文言句子 → 白话释义 + 关键词注释。
- 例：「'己所不欲，勿施于人'」→ 自己不愿意的，不要强加给别人——《论语·颜渊》。

## 二、输出格式（典籍介绍型）
```
【典籍】《XX》
【作者/编者】（朝代）XXX
【性质】（体例/类别）
【内容】核心内容概述
【价值】地位与影响（简）
```

## 四、易错点
1. **版本问题**：古籍版本多（通行本/注疏本），引用以通行权威版本为准。
2. **学术边界**：有争议的解读（如某典故出处多说法）要说明"一说"而非断言。
3. **中医/易学内容**：仅作文化了解，明确不构成医疗/决策建议（转介见 references/05）。
