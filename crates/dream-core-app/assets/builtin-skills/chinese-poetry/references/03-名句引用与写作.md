# 名句引用与写作

## 一、按场景找引用句（高频场景速查）

| 使用场景 | 推荐方向 | 示例句 | 出处 |
|---------|---------|--------|------|
| 工作总结/汇报 | 坚持/积累/奋斗 | 不积跬步，无以至千里 | 《荀子·劝学》 |
| 演讲开场 | 气势/格局 | 会当凌绝顶，一览众山小 | 杜甫《望岳》 |
| 论文引言 | 学思结合 | 学而不思则罔，思而不学则殆 | 《论语·为政》 |
| 人生感悟 | 豁达 | 宠辱不惊，闲看庭前花开花落 | 《菜根谭》 |
| 团队合作 | 众志成城 | 人心齐，泰山移 | 民间谚语 |
| 求职面试 | 自省 | 吾日三省吾身 | 《论语·学而》 |

## 二、引用四要素（给用户输出时必带）
1. **原句**（准确无误）
2. **出处**（篇名 + 作者 + 朝代）
3. **语境**（这句话原本在讲什么）
4. **适用建议**（用在什么场合合适/不合适）

## 三、引用规范提醒
- **写作引用**：直接引用需加引号 + 注明出处；学术论文按引用格式规范（GB/T 7714）。
- **避免误用**：常见名句有"被误读"的（如"执子之手"原意是战友，不是爱情）——引用前确认原意。
- **适度引用**：演讲/文案引用 1-2 句点睛即可，不要堆砌。

## 四、典型对话流
```
用户：写领导讲话，想引一句表达"实干/实践"的话
→ 输出候选句（如"纸上得来终觉浅，绝知此事要躬行"陆游《冬夜读书示子聿》）+ 出处辨析
→ 补充语境与使用建议
```
