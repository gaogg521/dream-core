# 票种字段规则与状态码

## 1. 查验字段规则

### 1.1 数电票 / 全电发票（20 位发票号码）

优先使用三要素查验：

| 字段 | 参数名 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| 发票号码 | `fphm` | 是 | 通常为 20 位发票号码 |
| 开票日期 | `kprq` | 是 | 格式 yyyyMMdd |
| 价税合计 | `fpje` | 是 | 票面价税合计金额，字符串传参 |

`fplx` 取值：
- `QDFP`（全电发票，编码 09）— `fpje` 必填
- `QD_PTFP`（全电普通发票，编码 0910）— 建议传 `fpje`
- `QD_ZYFP`（全电专用发票，编码 0920）— 建议传 `fpje`
- `QD_PAPER_ZYFP`（全电纸质专用发票，编码 0901）— 建议传 `fpje`
- `QD_PAPER_PTFP`（全电纸质普通发票，编码 0904）— 建议传 `fpje`

### 1.2 传统增值税发票（8 位发票号码）

8 位发票号码时，所有票种均需传 `fpdm`（发票代码），并根据票种补充额外字段：

| 发票类型 | `fplx` 枚举值 | 额外必填字段 |
| --- | --- | --- |
| 增值税专用发票 | `ZZS_ZYFP` (01) | `fpje`（不含税金额） |
| 货运运输业增值税专用发票 | `HYYSY_ZZS_ZYFP` (02) | `fpje`（合计金额） |
| 机动车销售统一发票 | `JDCXS_TYFP` (03) | `fpje`（不含税价） |
| 增值税普通发票 | `ZZS_PTFP` (04) | `jym`（校验码后 6 位） |
| 增值税普通发票（电子） | `ZZS_PTFP_DZ` (10) | `jym`（校验码后 6 位） |
| 增值税普通发票（卷式） | `ZZS_PTFP_JS` (11) | `jym`（校验码后 6 位） |
| 增值税普通发票（通行费） | `ZZS_PTFP_TXF` (14) | `jym`（校验码后 6 位） |
| 二手车销售统一发票 | `ESCXS_TYFP` (15) | `fpje` |
| 增值税电子专用发票 | `ZZS_ZYFP_DZ` (20) | `fpje` |
| 区块链发票 | `QKLFP` (100) | 按票面信息传参 |

### 1.3 金额处理规则

1. 金额只保留数字、负号和两位小数，去除 ¥、元、逗号等非数字字符。
2. 红字发票票面金额为负数属正常表现，不应去除负号。查验时按票面实际金额传入（如 `-30000.00`）。

### 1.4 字段补充优先级

1. 能从附件中识别出来的字段，不再让用户重复填写。
2. 只缺一个字段时，只追问这一个字段。
3. 缺多个字段时，优先追问当前查验必须字段。
4. 无法判断票种时，提示用户上传发票文件，或补充发票类型。

## 2. 参数校验规则

| 场景 | 校验规则 | 返回结果 |
| --- | --- | --- |
| `token` 为空 | 返回失败 | — |
| `token` 无效 | 返回失败 | 消息为 `应用标识校验失败!` |
| `fplx` 为空 | 返回失败 | — |
| `fphm` 为空 | 返回失败 | — |
| `fphm` 长度不是 8 或 20 | 返回失败 | — |
| `kprq` 为空或长度不是 8 | 返回失败 | — |
| `fpje` 必填但为空或非数字 | 返回失败 | — |
| `jym` 必填但为空 | 返回失败 | — |
| 8 位 `fphm` 且需要发票代码但 `fpdm` 为空 | 返回失败 | — |

## 3. 状态码表

| `result.status` | 说明 | 处理方式 |
| --- | --- | --- |
| `001` | 查验成功，发票一致 | 展示发票状态和票面信息；检查 `zfbz` 判断是否正常/作废/红冲 |
| `002` | 超过该张票当天查验次数 | 提示用户明天再试 |
| `003` | 超过该账户查验次数 | 提示账户查验额度已用完 |
| `004` | 超过服务器最大请求数 | 提示稍后重试 |
| `005` | 请求不合法 | 检查请求参数格式 |
| `006` | 查验成功，发票不一致 | 列出差异项，建议以平台返回为准 |
| `009` | 所查发票不存在 | 提示未查到，不判定假票，建议核对信息或稍后重试 |
| `105` | 查询发票不规范 | 检查发票参数是否规范 |
| `106` | 查验异常 | 提示稍后重试或转人工 |
| `108` | 请求不规范 | 检查请求格式 |
| `998` | 解析接口发生异常 | 提示稍后重试 |
| `999` | 接口重试超过次数 | 提示稍后重试 |
| `1001` | 发票金额输入不正确 | 提示用户核对金额 |
| `1002` | 发票校验码输入不正确 | 提示用户核对校验码后 6 位 |
| `1004` | 发票代码不正确 | 提示用户核对发票代码 |
| `1005` | 发票号码不正确 | 提示用户核对发票号码 |
| `1006` | 超过五年的发票不能查验 | 提示发票已超查验时限 |
| `1007` | 开票日期超过当前日期 | 提示开票日期不能晚于今天 |
| `1008` | 当前发票正在查验中，请稍后重试 | 提示稍后重试 |
| `1009` | 开票日期不正确 | 提示用户核对开票日期 |
| `1010` | 价税合计不正确 | 提示用户核对价税合计 |

## 4. 发票状态 `zfbz` 值

| `zfbz` 值 | 状态 | 说明 |
| --- | --- | --- |
| `0` | 正常 | 发票状态正常 |
| `2` | 作废 | 发票已作废，不建议用于报销/付款/入账 |
| `3` | 红冲 | 发票已红冲，不建议用于报销/付款/入账 |
| `8` | 异常（疑似全额红冲） | 实测数电普票被红冲后原票返回此值；票面信息仍可查询，但状态异常，不建议报销/付款/入账，需联系开票方确认 |
| 其他非 0 值 | 异常 | 状态码不在 0/2/3/8 范围内时，一律按「查到但状态异常」处理（对应 SKILL.md 5.2 节），提示联系开票方确认，不得按正常票处理 |

## 5. 外层响应码

| `code` | 说明 |
| --- | --- |
| `0` | 接口处理成功 |
| `101` | 接口处理失败 |
