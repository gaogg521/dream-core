# 天气查询

基于 wttr.in 免费天气 API，无需注册、无需 API Key，支持自然语言查询。

## 功能

- 查询指定城市当前天气
- 支持今天 / 明天 / 后天预报
- 支持多城市天气对比
- 内置 10 分钟内存缓存，减少重复请求
