# 五平台差异化发布指南

> 由 bid_publisher 维护。每篇文章产出时，按本指南生成 5 份差异化文案。

## 一、平台矩阵总览

| 平台 | 内容形式 | 最佳字数 | 标题风格 | 发布时间 | 封面规格 |
|------|----------|---------|----------|----------|----------|
| ① 微信公众号 | 图文长文 | 1500-2500字 | 专业深度、信息量大 | 07:15 | 900×500 |
| ② 视频号 | 短视频+文案 | 60-90秒脚本 | 悬念/冲击开头 | 12:00 | 1080×1920 |
| ③ 小红书 | 图文笔记 | 800-1200字 | emoji+口语+干货 | 07:30 | 1242×1660 |
| ④ 今日头条 | 短文/资讯 | 1000-1500字 | 数字+利益点 | 07:30 | 900×500 |
| ⑤ 抖音 | 短视频 | 45-60秒脚本 | 口语+快节奏+争议 | 12:00 | 1080×1920 |

## 二、差异化适配规则

### ① 微信公众号
- **结构**：标题 → 导语（痛点/故事）→ 3-5个论点（每论点含数据+案例+金句）→ 总结 → 行动建议 → 互动引导
- **排版**：段落≤4行；小标题加粗；关键数据用`**加粗**`；适当使用引用块
- **文末固定栏目**：「一句话总结」+「今日思考」（一个引导留言的问题）
- **引流**：文末嵌入视频号卡片（关联②）
- **禁忌**：不写"保证入库""包过"等违规表述

### ② 视频号脚本
- **结构**：0-5s 钩子（惊人数据/提问）→ 15s 痛点 → 30s 核心观点1 → 50s 观点2+案例 → 70s 观点3+方法 → 85s 总结+引导关注
- **BGM**：选择"知识类"轻快节奏，避免版权风险
- **字幕**：关键数据必须上字幕，字号≥36pt
- **封面**：深蓝/金色主色，大字居中，人物（如有）视线引导
- **引流**：评论区置顶公众号链接

### ③ 小红书
- **标题模板**：⚠️/🔥/📢 + 核心利益点 + emoji
- **正文**：口语化、碎片化、多用 emoji 分段
- **固定结构**：
  ```
  ⚠️ 先说重点：[一句话结论]
  
  📌 详细拆解：
  1️⃣ [要点1] + emoji
  2️⃣ [要点2] + emoji
  3️⃣ [要点3] + emoji
  
  💡 实操建议：[具体可执行的动作]
  
  ❓ 互动：你遇到过这种情况吗？评论区聊聊～
  ```
- **话题标签**：10 个，含行业大词+长尾词
  - #评标专家 #招标投标 #政府采购 #工程招投标 #专家入库 #职称评审 #评标技巧 #招投标法规 #投标避坑 #职业发展规划
- **引流**：评论区引导"更多干货看公众号同名账号"

### ④ 今日头条
- **标题 A/B 测试**：系统自动推 A/B 两套标题
  - A 版：数字利益型 → "罚款暴涨20倍！评标专家签字要管一辈子？"
  - B 版：疑问悬念型 → "招标投标法26年首修，专家要承担什么新责任？"
- **正文**：偏资讯口吻，开头直接给结论/数据，少用"我""笔者"
- **配图**：至少 3 张，含信息图/数据截图/封面
- **话题**：5 个，偏新闻类
  - #招标投标法修订 #政府采购新规 #评标专家 #工程招投标 #政策法规解读
- **引流**：可放公众号名称（头条允许适度引流）

### ⑤ 抖音
- **脚本结构**（45-60秒）：
  ```
  0-3s：🔥 钩子
    "评标专家注意！签字要管一辈子了！"
  3-15s：😱 痛点/冲突
    "以前评完标签完字就完事，现在不一样了..."
  15-35s：📖 核心知识
    "三个变化你必须知道：第一...第二...第三..."
  35-50s：✅ 行动建议
    "现在立刻做两件事：第一查你的专业类别..."
  50-60s：👉 引导
    "关注我，每天一条招投标干货"
  ```
- **口播风格**：语速快、情绪饱满、多用"你""你的"
- **字幕**：关键数字/关键词必须上字幕
- **封面**：深红/黑色主色，超大字+⚠️/🔥图标
- **话题**：5 个
  - #评标专家 #招标投标 #政府采购 #投标技巧 #政策解读
- **引流**：简介放公众号名称

## 五、合规红线（五平台通用）

| 禁止表述 | 合规替换 |
|----------|----------|
| "保证入库" | "提高入库成功率的方法" |
| "包过/必过" | "高频考点+答题技巧" |
| "内部渠道" | "官方公开渠道汇总" |
| "串通/围标技巧" | （任何形式都不写） |
| "绝对/100%" | "大多数情况/经验表明" |
| "收费代办" | （不提供此类服务） |
