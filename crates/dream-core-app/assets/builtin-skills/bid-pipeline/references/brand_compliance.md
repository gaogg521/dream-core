# 品牌与合规红线（Brand & Compliance Red-lines）

本文件是「招投标内容智作团」上线前必须守住的口径与红线，供法规审核官把关、全体角色参照。

## 一、内容定位（不改）

- 垂直领域：**评标专家申报实务**。单篇独立传播，默认不横向对比其他库、不蹭无关热点。
- 风格：专业权威、实用干货、清晰易读；符合首发、原创、人工写作标准。
- 账号矩阵（发布管家登记用）：公众号/视频号「劳同冶」，头条/抖音/小红书「老爺保號」。

## 二、硬性红线（命中即打回）

1. **禁用国家/党政/公职人员名义**为内容背书、引流或暗示官方关系。
2. **禁止第三方未授权信息**：不得引用未公开的内部资料、未授权的他人数据。
3. **禁止虚构**：政策、数据、案例须有出处（据 XX 公告 / 官方平台），不得编造。
4. **禁止绝对化/承诺性表述**：如「包过」「100% 入库」「官方指定」「稳过」。
5. **广告法与平台规范**：不碰医疗、不涉及敏感话题、标题不标题党、不夸大。
6. **品牌一致性**：沿用统一品牌与垂直定位；封面不得有乱码、图标叉、布局重叠、对比度不足。

## 三、可信表述替代

- 用「据 XX 省 XX 公告」「以官方最新发布为准」替代确定式断言。
- 用「常见卡点」「多数地区要求」替代「一定」「全部」。
- 案例去敏：不点名具体单位/个人，不泄露非公开信息。

## 四、发布前四项校验（发布管家执行）

- `check_no_leak.py`：敏感词/未授权信息泄露
- `check_topic_dup.py`：选题去重（避免与近期已发重复）
- `check_ai_taste.py`：AI 味/机械感（须人工可读、有温度）
- `check_wx_tt_depth.py`：公众号/头条深度达标（非浅水稿）

任一不过 → 回传主理人，由主理人决定打回对应阶段修订。
