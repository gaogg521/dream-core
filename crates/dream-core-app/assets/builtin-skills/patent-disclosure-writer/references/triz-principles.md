# TRIZ 辅助的专利围墙设计

仅在用户要求专利布局、规避设计、替代实施方式或全案输出时读取。TRIZ 用于系统性提出候选方向，不能代替实施证据、现有技术检索或法律判断。

## 三类围墙

1. **替代实施**：改变关键技术手段，但保持核心问题—机制—效果链。例如用不同传感、调度、编码、模型或通信路径实现同一功能。
2. **上下游保护**：保护输入采集/预处理、核心处理、输出执行/反馈、运维监测等相邻环节，避免竞争者只替换链路位置。
3. **低成本简化**：减少部件、算力、材料或交互步骤，同时保留最低可用机制，覆盖经济型实现和规避版本。

每个候选方案必须写：与核心方案的共同点、区别点、技术问题、实现路径、预期效果、证据等级、待验证事项、与核心申请的重叠/单一性风险。

## 推演流程

1. 把核心矛盾写成“提高 A 会恶化 B”。
2. 选择 2—5 个与矛盾相关的原理，提出可实现的技术变化。
3. 回到原始材料核对是否有机制支撑；没有支撑的标为候选研发方向。
4. 对候选方向做现有技术检索，排除明显常规方案。
5. 按保护价值、证据强度、侵权可检测性和与核心主题的重叠度排序。

## 推荐输出

先用一张表比较三类围墙，再用层级图显示核心主题与候选主题。不得用无连接的流程图冒充逻辑图。布局图只表达主题关系，不暗示方案已经完成或必然可授权。
