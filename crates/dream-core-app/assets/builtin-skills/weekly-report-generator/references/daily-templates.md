# 日报模板（按场景）

日报比周报更短、更聚焦「今天」。以下模板按场景区分。

---

## 1. 标准日报（默认）

```markdown
## 今日完成
- 事项：结果/数据
- 事项：结果/数据

## 今日问题
- 问题：影响 + 解决进展

## 明日计划
- 计划事项：预期结果

## 备注
- 需要同步 / 求助的信息
```

---

## 2. 极简版（团队快报，适合每天给同事看）

```markdown
【今日】完成 X、Y、Z；卡在 A（等 B 回复）。
【明日】做 M、N。
【求助】需要 C 提供 D。
```

要点：三行封顶，每条用分号连接，卡点单列。

---

## 3. 数据型日报（销售 / 运营 / 电商）

```markdown
## 今日数据
| 指标 | 今日 | 昨日 | 说明 |
|---|---|---|---|

## 今日动作
- 动作 1：结果
- 动作 2：结果

## 异常与跟进
- 异常：原因 + 处理

## 明日重点
- 重点事项：预期
```

---

## 4. 研发日报

```markdown
## 今日完成
- 【开发】XX 功能：进度/结果
- 【修复】Bug 编号 + 修复说明

## 阻塞
- 阻塞项：原因 + 需要谁支持

## 明日计划
- 计划：预期产出

## 风险
- 风险：影响 + 应对
```

---

## 5. 出差 / 外勤日报

```markdown
## 今日行程
- 时间地点 + 见谁 + 结论

## 今日收获
- 关键信息 / 客户反馈

## 明日安排
- 行程计划

## 费用与报销
- 待整理事项（如适用）
```

---

## 通用要点

- 日报默认「今日完成 + 明日计划」双栏即可，其余按需增删。
- 卡点/阻塞必须在日报里显性化，避免压在心里。
- 用户连续多天提交时，可生成「周报汇总」——把多条日报合并去重成周报。
