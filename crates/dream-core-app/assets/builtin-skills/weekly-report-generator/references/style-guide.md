# 写作风格指南

本文件是周报/日报写作的通用规范，AI 生成内容时逐条遵守。

## 一、动词开头，拒绝空话

**忌用**（空动词，删除或替换）：

- 进行了、开展了、负责了、推进了、参与了、贯彻落实了
- 赋能、抓手、闭环、颗粒度、对齐、拉通、打法、心智、势能

**改用**（具体动作 + 结果）：

| 弱表达 | 强表达 |
|---|---|
| 负责了首页改版 | 完成首页改版，首屏加载从 3.2s 降到 1.1s |
| 开展了用户调研 | 访谈 12 位核心用户，整理出 5 类需求 |
| 推进了项目 | 项目按期上线，覆盖 3 个业务线 |
| 参与了周会 | （直接删掉，无信息量） |

## 二、量化优先

- 能用数字就不用形容词：说「提升 30%」，不说「显著提升」。
- 没有精确数据时给范围或量级：约、近、10+、翻倍。
- 实在没有数据，写「完成了 X」而非「很好地完成了 X」。

## 三、句式规范

- 每条成果 1–2 行，分点 ≤ 6 条；超过就合并同类项。
- 短句为主，长句拆开。
- 避免「综上所述、总而言之、此外、值得一提的是」等套话。

## 四、语气与立场

- 客观陈述事实，不邀功、不甩锅、不吹捧。
- 问题描述聚焦「事实 + 影响 + 需要的支持」，不做人身归因。
- 对上级：结论先行，数据支撑，问题带方案。
- 对团队：突出协作与进展，弱化个人色彩。
- 对客户：聚焦交付与价值，隐藏内部过程。

## 五、去 AI 味清单

生成后自查，命中即改：

1. 是否用了「赋能/抓手/闭环」等黑话？→ 删
2. 是否出现「综上所述/总之」？→ 删
3. 是否每段开头都是「首先/其次/然后」？→ 改为直接陈述
4. 是否有编造的数字或事实？→ 改为「待补充」
5. 是否超过 3 个排比堆砌？→ 精简
6. 句子是否读起来像宣传稿？→ 改口语化、具体化

## 六、数字与格式

- 百分比、数量用阿拉伯数字；「3 个」「12 位」「30%」。
- 日期写「9 月 3 日」，时间写「14:00」。
- 涉及金额默认用「¥」，涨跌配色遵循用户所在地区习惯（A 股场景：涨红跌绿）。
