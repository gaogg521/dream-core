# 周报模板（按角色分风格）

以下模板供 AI 根据用户角色选用。每个模板给出「结构侧重」和「示例」，示例仅为格式示范，内容由 AI 结合用户素材生成。

---

## 1. 技术周报（开发 / 运维 / 测试 / 数据）

**侧重**：交付、技术难点、线上稳定性、排期。

```markdown
## 本周概览
一句话总结：完成了什么版本/需求，线上是否稳定。

## 本周完成
- 【开发】完成 XX 功能：覆盖 N 个场景，接口 QPS 达到 X
- 【优化】首屏加载 3.2s → 1.1s
- 【修复】修复 XX Bug 共 N 个，其中 P0 级 M 个
- 【协作】支持 XX 团队接入，联调 N 个接口

## 线上 / 质量数据
| 指标 | 本周 | 上周 | 说明 |
|---|---|---|---|
| 可用性 | 99.9% | 99.8% | 无 P0 事故 |
| 缺陷数 | 5 | 8 | 收敛中 |

## 问题与风险
- XX 模块依赖第三方接口不稳定，已加降级，需对方下周修复

## 下周计划
- 【高】完成 XX 版本提测，预期周五上线
- 【中】重构 XX 模块，减少重复代码

## 需要的支持
- 需要 XX 团队提供测试环境数据
```

## 2. 产品周报

**侧重**：需求进展、版本节奏、数据表现、用户反馈。

```markdown
## 本周概览
版本 V1.3 完成开发并进入内测。

## 本周完成
- 【需求】输出 XX 功能 PRD，完成评审
- 【版本】V1.3 完成开发，覆盖 N 个需求点
- 【数据】周活 X 万，环比 +Y%
- 【调研】访谈 N 位用户，确认 5 个高优需求

## 数据表现
| 指标 | 本周 | 环比 | 说明 |
|---|---|---|---|

## 问题与风险
- 内测反馈：XX 流程体验差，需下周优化

## 下周计划
- 【高】V1.3 公测并收集反馈
- 【中】启动 XX 需求调研
```

## 3. 销售周报

**侧重**：业绩数字、客户进展、回款、漏斗。

```markdown
## 本周概览
签约 X 单，金额 ¥Y，完成目标 Z%。

## 业绩数据
| 指标 | 本周 | 目标 | 达成率 |
|---|---|---|---|
| 新签 | X 单 / ¥Y | ¥A | Z% |
| 回款 | ¥B | ¥C | W% |

## 本周完成
- 签约客户 XX、XX，合计 ¥Y
- 拜访 N 家，新增商机 M 个
- 完成 XX 方案演示，进入商务谈判

## 问题与风险
- 客户 XX 预算下调，需重新报价

## 下周计划
- 【高】推进 XX 客户签约
- 【中】跟进 M 条商机

## 需要的支持
- 需要 XX 资源支持大客户打单
```

## 4. 运营周报

**侧重**：活动、内容、增长、转化。

```markdown
## 本周概览
XX 活动上线，带来新增 X 万、转化率 Y%。

## 核心数据
| 指标 | 本周 | 环比 | 说明 |
|---|---|---|---|

## 本周完成
- 【活动】上线 XX 活动，曝光 X 万，转化 Y%
- 【内容】产出 N 篇内容，总阅读 X 万
- 【增长】新增用户 X 万，环比 +Y%

## 问题与风险
- XX 渠道成本上升，ROI 降至 X

## 下周计划
- 【高】XX 活动二期
- 【中】优化 XX 转化路径
```

## 5. 管理者周报（团队负责人 / 部门）

**侧重**：团队产出、关键决策、跨部门协同、目标达成。

```markdown
## 本周概览
团队完成 XX，整体进度 X%。

## 关键产出
- 团队交付 XX，覆盖 N 项
- 关键决策：XX（背景 + 结论）

## 目标达成
| 目标 | 进度 | 备注 |
|---|---|---|

## 风险与依赖
- XX 项目延期风险，已协调资源，需关注

## 下周重点
- 推动 XX 落地；完成 XX 评审

## 需要上级支持
- 需要 XX 资源 / 决策
```

## 通用选择建议

- 用户没说明角色时，用「通用结构」（见 SKILL.md 的周报标准结构）。
- 发给客户/外部的，用「交付视角」，突出成果与价值，隐藏内部风险细节。
- 发给直属上级的，结论先行 + 数据 + 问题带方案。
