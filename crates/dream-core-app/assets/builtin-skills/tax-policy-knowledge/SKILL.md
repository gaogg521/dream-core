# 财税政策知识库 v3.18.9

> 全量财税知识库 · 多维度风险指标模型 · 合规应对指引 —— 三大专业底座，全面、专业、可落地

本技能是面向企业合规（需求侧）与中介机构执业（供给侧）的统一财税合规助手。围绕**三大专业底座**展开：

**① 全量财税知识库（全面）** —— 覆盖 13 个税种 + 7 项地方税费 + 6 项社保费 + 新业态，政策库自动联网更新、重大新规（增值税法实施、发票正负面清单等）即时同步；每条结论标注政策依据并可溯源，区分国家 / 地方 / 行业口径，避免一刀切。

**② 多维度风险指标模型（专业）** —— 491 项量化指标按**全税种 / 全行业 / 全地区 / 全专题 / 全组合**五大维度组织（**唯一口径 491 项**，细分见下方「分类风险指标模型」），自动评分定位虚开虚抵、阴阳合同、私户收款、税负异常、关联交易失当、新业态隐匿收入等高风险点，匹配风险等级与整改优先级。

**③ 合规应对指引（可落地）** —— 正负面清单明确红线与合规标准；七流一致（合同/发票/资金/货物服务/业务/财务/收入/成本/人员八流交叉核对）、金额验证与分层整改步骤齐备；风险自查报告、合规建议、整改清单一键生成；配套真实案例画像与实操流程。

## 快速开始

直接提问即可，无需任何命令。本技能覆盖「**企业合规 / 合同模板 / 发票合规 / 事务所交付 / 经营八大陷阱**」五大场景一条入口，以下代表性问答/段落可直接复制提问并改造。

**① 企业收入合规 · 私户收款风险**（含金税四期触发）

> 问：用老板个人卡收部分货款、未计入公司账，在合规上属于哪类风险？
> 答：属「资金流与收入流背离」高风险——依据增值税/企业所得税/征管法须补缴税款+滞纳金，可处 0.5–5 倍罚款，情节严重涉偷税；金税四期实现平台/银行/发票四流自动交叉比对。本技能据此定位风险指标、给出风险等级，并输出「补申报 + 发票红冲 +（合同/发票/资金/货物流/收入流/成本流/人员流）七流一致证据链」整改清单。

**② 关联交易 · 转让定价合规**（含合同涉税条款审核）

> 问：集团内两家关联公司低价互开发票分摊成本；或一份销售合同有哪些涉税风险？
> 答：关联交易须符合独立交易原则，定价明显偏离公允价值可触发特别纳税调整+利息补征。本技能按「关联交易失当」风险指标评估并给出行业利润率合规定价区间，提示同期资料与功能风险分析备查清单。合同审查覆盖兼营/混合销售是否分别核算、价外费用是否计税、阴阳合同/拆分合同/关联交易定价公允性、工程政采补充合同是否规避招标。

**③ 政策溯源与中小场景**（含小规模 + 主播带货 + 大政落地）

> 问：（A）月销售额 8 万增值税怎么算？（B）主播带货收入怎么交个税？（C）最新留抵退税 / 数电票政策我们行业怎么适用？
> 答：（A）小规模纳税人月销售额 < 10 万，**免征增值税**（普票部分）。（B）直播带货佣金属**劳务报酬所得**，平台/MCN 代扣代缴，年度汇算后并入综合所得。（C）每条结论均标注政策依据并可溯源，区分国家/地方/行业三类口径；同步提示生效时点、申报表填列与留存备查要求，重大新规即时同步。

**④ 事务所供给侧 · 全量合规体检交付**

> 问：作为税务师，怎样用本技能为客户做全量合规体检并交付报告？
> 答：进入「通用全量精准扫描」场景，一键生成风险评分/等级/整改优先级，输出可追溯的风险自查报告与合规建议书。风险自查 / 指标模型 / 七流一致 / 发票合规 可直接用于客户体检、尽调底稿与交付成果，三级复核后出具；合同模板 + 合规报告一键生成覆盖常年顾问(T1)至跨境架构(T7)业务约定书、可行性报告、实施计划、台账。**进阶执业能力**（三级复核/质量控制/数据安全分级/AI 数智化执业/IMA人才培养）由税务师合规咨询执业专题专项承接，本包仅作共享底座与入口。

**⑤ 100+ 合同模板库 + 发票合规正负面清单（2026新规）**

合同覆盖**劳动人事/买卖交易/租赁物业/服务合作/建设工程/金融投资/知识产权/数据合规/政府合同/生活服务/财税服务(T1-T7)/合规咨询**十二类，涉税条款可同步审核并出具风险清单，直接说「我要一份 XX 合同模板」即可获取。发票方面基于税务总局《发票合规正负面清单》：**正面清单**（合规开票标准/流程/要素/时限）+ **负面清单**（虚开/空壳企业/对开环开/恶意红冲/开票经济等发票合规红线，违规含罚款/补税/刑事责任）。

**⑥ 经营合规八大陷阱识别（企业侧刚需）**

针对百亿级虚假贸易连环爆雷、国资「零容忍」监管，本包内置**经营合规八大陷阱**识别与整改：①**虚假贸易 / 空转走单 / 融资性贸易 / 循环贸易**——以国资委「十不准」为红线 + 七流一致核验（货物流/资金流/票据流/合同流不一致即预警）一键定位货权缺失/闭环交易/异常价差；②**违规挂靠（资质出借）/ 假冒国企 / 供应商主体异常 / 围标串标**——覆盖《建筑法》《招标投标法》《政府采购法》及国资委假冒央企黑名单机制，后果含没收违法所得/限制投标/串通投标罪；③**追责高压**——国资委 46 号令（2026.1）终身追责 + 穿透监管，最高法认定循环/融资性贸易为隐性借贷、买卖合同无效。完整「十不准」逐条、七流一致经营自查表、案例库与整改闭环，及钢铁托盘/闭口循环、建筑挂靠/围标等特例，均已纳入「经营合规风险自查 / 钢铁关联交易风险 / 建筑行业税务」专题，对话中直接提问即可调阅。

## 分类风险指标模型

在「多维度风险指标模型」基础上，按**全税种 / 全行业 / 全地区 / 全专题 / 全组合**五大维度组织的量化指标体系（唯一口径 **491 项**），自动评分定位高风险点并给出整改优先级；各维度类别与指标数量如下。完整指标逻辑、评分规则与整改模板进入问答即可查看；想跑通「指标扫描 → 报告 → 应对」闭环，见下方「三流联动风险指标与自查应对（闭环实战）」。

**① 按税种分（90 项）**：增值税类(32) · 企业所得税类(28) · 个人所得税类(12) · 其他税种类(18)

**② 按专题分（146 项）**：开票经济专项(36) · 资金流监控(12) · 经营数据异常(16) · 关联交易(10) · 跨境税务(12) · 特殊行业(14) · 电商平台经营(9) · 跨境电商零售进口(2) · 网红直播/带货(10) · 平台报送(3) · 医美电商(2) · 黄金珠宝(1) · 直播电商细粒度(8) · 电商经营细粒度(6) · 跨境电商细粒度(5)

**③ 按行业分（65 项）**：电商/直播(10) · 建筑(5) · 房地产(5) · 金融服务(5) · 教育(5) · 医疗健康(5) · 制造业(5) · 高新科技(5) · 开票经济专项(12) · 电商新业态扩展(8)

**④ 按地区分（30 项）**：全国级(10) · 省级差异(10) · 区域化(10)

**⑤ 按组合分（58 项）**：税种×行业(15) · 行业×地区(10) · 专题×税种(10) · 专题×行业(10) · 开票经济专项组合(8) · 跨区域(5)

> 五大维度合计覆盖项可跨维度重叠（去重后唯一口径 **491 项**）；指标随监管重点持续扩展（如新业态、反向开票、再生资源等专项）。

## 重要提示与边界声明

**重要提示**

1. **计算结果仅供参考**：所有税额测算、优惠判断、风险评分均为辅助参考，**不构成税务申报、审计或法律意见**。
2. **专业事项请咨询执业人员**：税务筹划、争议解决、稽查应对等需结合企业实际，由执业税务师/律师量身定制。
3. **数据以官方为准**：政策时效性强，个案结论可能因地区、行业、时间而异；涉及重大利益请向主管税务机关或专业人士二次确认。

**边界（本技能不做的）**

- **不代办**：实时申报、缴款、退税、注销等需登录电子税务局的操作
- **不代理**：税务行政复议、诉讼、鉴证等需执业资质的法律事务
- **不跨域**：医疗、法律、投资理财建议等非财税问题
- **不担保**：政策时效与个案结论以税务机关/执业税务师最终认定为准

**服务说明**

- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**隐私保护**

- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据。
