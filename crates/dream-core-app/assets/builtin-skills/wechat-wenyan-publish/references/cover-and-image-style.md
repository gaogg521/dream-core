# 封面与配图风格规范

## 封面（Codex 风，900×383）

- 底色：白 → 极浅绿渐变（#fafaf9 → #f0fdfa），右下/左上两团高斯模糊的绿光晕
- 主色：绿 #10a37f；标题黑 #171717；副标题深灰蓝 #374151；小字灰 #71717a
- 版式：**左文右图**，中部 1px 浅灰分隔线（x=492）
  - 左栏：左侧 6px 绿色竖条 → 眉题（绿色小字，如"AI · 生态观察 · 2026-09-02"）→ 主标题（Noto Sans CJK **Black** 38px）→ 副标题（Bold 20px）→ 底部一排圆角 pills（绿色描边浅绿底）
  - 右栏：图示占 372px 宽，圆角 16 裁剪；默认是"1 个中枢 → 3 个能力块"hub 模板，可用 `--right-svg` 换自定义
- 字体：Noto Sans CJK Black / Bold（脚本按 Linux/macOS/Windows 常见路径自动查找）

## 铁律

> **封面一律不加作者署名。** 图上不写"作者名·"式水印、不加任何署名元素；作者只出现在 API 的 author 字段。

## 正文配图（SVG → PNG）

- 画布 780 宽（高按内容），viewBox 与画布同尺寸；**白色背景** + 1px `#e2e8f0` 圆角边框
- 字体：`'Noto Sans SC','PingFang SC','Microsoft YaHei',sans-serif`（SVG 内 font-family 声明）
- 配色：主强调 `#10a37f` 绿；次强调 `#3b82f6` 蓝 / `#8b5cf6` 紫 / `#f59e0b` 橙（只做区分用，别全上）
- 文字层级：标题 18px/700、小节 13px/700、正文 11-12px、注释 10.5px `#6b7280`
- 数据/流程类：中文标签、箭头用 marker-end、几何坐标按内容算准（如扇形箭头指向目标中心，别写死估数）
- 转换：`gen_diagrams.py a.svg b.svg`（scale=2 → 1560 宽高清），依赖 cairosvg

## 常见错误

1. 封面出现署名水印 → 删除署名元素
2. SVG 直接进正文 → 微信拒，先转 PNG
3. 箭头错位（写死 y 坐标与目标框不齐）→ 按目标框几何中心反推坐标
4. 主题色 hex 被 wenyan 转成 rgb() 属正常，不影响呈现
