# 旧照片修复（Old Photo Restorer）

## Overview

通过多模态大模型图生图能力，对老旧照片做翻新增强：去除噪点颗粒、划痕、折痕、污渍霉斑，修补破损缺块，提升清晰度与对比度。**核心原则是「修复」而非「重绘」**——必须保留原图的人物五官、构图、年代服饰与场景细节，不擅自上色、不改变人物长相、不换背景。

## 工作流（Workflow）

### Step 1 — 读图诊断

1. 先用 Read 工具读取照片（本技能依赖多模态读图能力），确认图片真实存在的问题。
2. 将问题归类（可多选）：
   - **噪点颗粒**：画面遍布细密颗粒/雪花感，多见于低光翻拍、高感光胶片
   - **划痕**：贯穿画面的白色/深色细线，多为物理刮伤或扫描线
   - **折痕/褶皱**：照片纸张折出的宽条状明暗带
   - **污渍/霉斑**：局部黄褐斑块、水渍、霉点
   - **破损缺失**：缺角、撕裂、大面积颜料剥落，画面信息缺失
   - **模糊**：整体或局部失焦、轻微抖动模糊
   - **褪色/偏色**：泛黄、泛红、颜色黯淡或色偏
   - **分辨率低**：整体发虚、锯齿明显，需要清晰化增强
3. 若图片问题严重到难以判断内容（如大面积破损、几乎全黑），先告知用户修复预期可能有限，询问是否仍继续。

### Step 2 — 制定修复策略

- **单一或轻度问题**（如仅少量划痕+噪点）→ 一次图生图完成。
- **中度多问题**（如泛黄+噪点+划痕）→ 一次调用，prompt 中并列列出所有问题（参考 prompt-library 拼接模板）。
- **重度破损**（大面积缺失/撕裂）→ 分两步：
  1. 先做「结构修复」（补全破损区域，不求细节完美）
  2. 把第一次输出图作为输入，再做「整体增强」（去噪、清晰化）
- **尺寸选择**：按原图构图选择输出尺寸 —— 横图 `1536x1024`，竖图 `1024x1536`，方图/不确定 `1024x1024`。
- **黑白照片**：默认保持黑白只做翻新，除非用户明确要求上色。

### Step 3 — 执行图生图修复

1. **调用前必须告知用户**：每次 ImageGen 调用会消耗约 5-10 个独立积分（credits）。
2. 调用 ImageGen（image-to-image），传参：
   - `image`: `[原图路径]`
   - `prompt`: 按 references/prompt-library.md 的模板组装（修复指令 + 具体问题 + 保真约束）
   - `size`: 按 Step 2 选择
   - `quality`: `"high"`
   - `input_fidelity`: 修复场景建议设 `"high"`（越高越贴近原图，避免模型自由发挥改变人物/场景）
   - `output_dir`: 输出到当前工作目录下 `photo-restore-output/`（不存在则创建）

### Step 4 — 检查结果

1. Read 修复结果图，与原图对比核验：
   - 划痕/噪点/折痕是否消失
   - 人物五官、构图是否保持（无「换脸」「变形」「加元素」）
   - 是否出现新的伪影、过度平滑的塑料感、文字乱码
2. 若仍有残留问题 → 把当前结果图作为输入再次修复（二次精修模板见 prompt-library），最多 2-3 轮；若模型倾向性改写原貌，可在下一轮加强保真约束。
3. 若结构发生明显错误改变（人物变了、背景换了）→ 重新调用，prompt 改用更强的「严格保真」模板，并提高 input_fidelity。

### Step 5 — 去水印与交付

- **默认去水印（本技能定位为无水印交付，此步必做）**：当前 ImageGen 输出右下角会带默认"AI 生成"水印，传空 `footnote` 无法关闭，必须运行 `scripts/remove_watermark_crop.py` 对修复结果做底部小范围裁剪（默认裁掉底部 80px，对人物主体几乎无影响）：
  ```bash
  python scripts/remove_watermark_crop.py <input.png/jpg> <output.png/jpg> [crop_height]
  ```
  裁剪后的文件命名加上 `_no_watermark` 后缀，并删除带水印的中间产物，只保留无水印版。
- 同时展示原图与无水印修复图（本平台 传入两个路径，修复图放前面）。
- 汇报要点：诊断出的问题清单、实际执行了几轮修复、每轮做了什么、残留的无法完美恢复的部分（如大面积信息缺失只能修补不能复原）。
- 若进行了分步修复，中间产物一并说明但不强制展示。

## 提示词撰写规范

完整可复用模板与分场景段落见 `references/prompt-library.md`。拼装规则：

```
[核心指令] + [问题清单，逐条说明] + [保真约束（默认必带）] + [黑白/彩色说明（按需）]
```

保真约束默认必带，防止模型重绘：

> Preserve the original composition, faces, clothing, background and historical character. Do NOT restyle, do NOT redraw faces, do NOT change backgrounds, do NOT add or remove objects, do NOT colorize unless asked.

中文等效约束：

> 保持原图构图、人物五官、服饰与背景不变，不要重绘、不要改变人物长相、不要更换背景、不要增删物体，除非用户要求否则不要上色。

## 注意事项

- **一次只修一张**：ImageGen 虽支持多图输入（用于图间风格参考），但修复任务必须逐张独立调用，避免串扰。
- **不擅自上色**：修复与上色是两件事，用户未要求时不得在 prompt 中暗示上色。
- **不美化**：修复不等于美颜。不得让照片变「磨皮人像写真」，需保留岁月痕迹（如胶片的自然颗粒可适当保留，只去除破坏性噪点）。
- **历史文字/匾额/招牌**：若照片含文字，提醒模型保持文字原样（若原图文字已模糊，修复后可能产生乱字，属正常限制，如实告知用户）。
