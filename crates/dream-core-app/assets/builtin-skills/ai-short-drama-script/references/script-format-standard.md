# 剧本格式双体系标准（投稿真人版 × AI 视频版）

> 知识截止 2026-09（2026-09-06 联网核验；格式口径参照短剧剧本格式规范 v2.0、平台投稿通用标准、番茄/红果投稿经验贴）
> 路由规则：需求含「投稿/拍摄/真人/过稿」→ 用体系一；含「AI/即梦/可灵/小云雀/分镜/出片」→ 用体系二；未指明 → **双体系同时给**（先体系一正文，再附体系二分镜表）。

## 体系对照表

| 维度 | 体系一：投稿/真人拍摄 | 体系二：AI 视频生成 |
|---|---|---|
| 接收方 | 人类编辑/导演/演员 | AI 大模型 + 人类导演 |
| 单位 | 以「场」为单位 | 以「镜」为单位 |
| 核心要求 | 人类可读、信息完整 | 机器可解析、提示词工程化 |
| 动作写法 | `△` 三角符号开头 | `（圆括号）`括起 |
| 对白格式 | `角色名：对白` | `角色名：（语气）对白` |
| 场景标题 | `场1-1 地点 日/夜 内/外` | `【场景1：内景 - 地点 - 时间（秒）】` |
| 集头 | `【第X集】` | `━━━ 第X集《标题》━━━` |
| 叙事结构 | 三幕/起承转合 | H-B-C-E（Hook-Build-Climax-Ending） |
| 分镜表 | 无 | **必须有**（镜号/景别/运动/提示词） |
| 投稿要求 | 前 5 集 + 大纲 | 全剧分镜表 + 角色资产 |

## 体系一 · 完整稿件结构（投稿标准顺序）

```
第一，剧本信息：剧名 / 题材 / 总集数
第二，人物小传：每人 3-5 行（标签 + 核心特征 + 2 个视觉化特征）
第三，整体故事大纲：300-500 字，讲清起承转合四阶段
第四，分集剧本正文
```

### 单集固定排版模板

```
第X集

场景：XX 地点
时间：白天/夜晚
人物：角色A、角色B

△动作/场景描述（只写看得见的）
角色A：（情绪+动作）台词内容
角色B：（情绪+动作）台词内容

△动作推进
角色A os：内心想法

【闪回】△回忆场景【闪出】

本集钩子：结尾悬念/反转/危机铺垫
（第X集完）
```

### 符号速查

| 符号 | 用法 | 示例 |
|---|---|---|
| `场X-Y` | 第X场第Y镜 | 场1-1 |
| `日/夜` `内/外` | 时间与空间 | 内 夜 |
| `△` | 动作/场景描述 | △徐溺转身离开 |
| `os` | 内心想法 | 徐溺os：他在说谎 |
| `VO` | 画外音 | VO（电话）：喂？ |
| `【闪回】/【闪出】` | 回忆起止 | — |

### 过稿 5 大标准（自查清单）

- [ ] 开篇有爆点（暧昧/冲突/大场面）
- [ ] 有画面感和节奏感
- [ ] 台词精简（≤2 行/人）
- [ ] 单集 ≥500 字，全剧人设 ≤20 个
- [ ] 前 30 集爆点密集

### 投稿 12 项核心要求（权重口径）

| 模块 | 权重 | 要点 |
|---|---|---|
| 基础硬性 | 30% | 格式三要素（内外景+场景+时间）、「角色名+(动作)+对话」结构、镜头/运镜/转场标注、单集 800-1500 字（对应 3-5 分钟成片）、原创声明与版权意向书、是否已投他平台 |
| 创作核心 | 50% | 黄金 3 秒（前 120 字内出现冲突/悬念/视觉奇观）、每集钩子、题材适配（悬疑探案 35% / 情感都市 28% / 青春成长 22% / 玄幻仙侠 15%）、人物命运 3 转折点、每角色 ≥2 个视觉化特征、每 300 字 1 悬念节点、3-2-1 节奏模型（3 集铺垫→2 集爆发→1 集收尾）、每集 1 视觉爆点+2 情感爆点 |
| 进阶加分 | 20% | 分镜脚本、BGM 情绪曲线、5 秒样片、同类完播率对比、热点话题关联、受众画像、广告植入点（≥3）、互动环节、IP 衍生路线 |

### 平台分级投稿法
- 头部平台（腾讯/优酷等）：需完整季剧本 + 商业化方案
- 中腰部（抖音/快手等）：接受单集试投 + 数据测试
- 新锐平台：灵活度高，可谈分成

## 体系二 · AI 视频剧本结构（机器可解析）

```
━━━ 第X集《标题》━━━
【场景1：内景 - 宴会厅 - 夜（0-15秒）】
【情绪基调：压抑→爆发】【镜头：全景→女主特写】
（苏若，22岁，洗旧运动服，短发素颜，眼神克制。首次出场。）
苏雪：（轻蔑）你也配？
苏若：（平静）你说完了？
【音效：酒杯碎裂】
▶ 下集钩子：……
```

**AI 体系硬性附加项**：①角色首镜一次性锁定外貌锚点（后续每镜粘贴**完全相同**的描述段落，不得同义改写）②单镜只保留 1 个核心动作 ③分镜表七列齐全（镜号|画面|台词|景别|运镜|时长|AI 提示词）④文字招牌/门牌类静态图先出再转视频。

## 通用排版铁律（两体系共通）

1. 每集居中加粗大标题；每场清晰标注场景/时间/出场人物；
2. 人物尽量用全名（便于统筹）；描述具体可拍（"披着湿漉漉长发的女子伏在礁石上" 而非 "她很伤心"）；
3. 每集场景转换 ≤3 次；
4. 台词适配竖屏，单句 ≤15 字为佳；关键信息用动作代替对白（"摔离婚协议" > "我们离婚吧"）；
5. 标志性动作符号化：总裁扯领带=动怒、握拳发抖=隐忍。
