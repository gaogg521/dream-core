# 剧本格式规范与分集模板（产出体例硬标准）

> **格式路由（2026-09 升级）**：本文件为通用体例速查。完整的「真人投稿体系 vs AI 视频体系」双标准对照、过稿 5 标准、投稿 12 项要求见 @references/script-format-standard.md；分镜表七列与角色一致性方案见 @references/ai-video-pipeline.md。需求含「投稿/拍摄/真人」→ 用投稿体系；含「即梦/可灵/小云雀/分镜」→ 用 AI 视频体系；未指明 → 双体系都给。

## 一、剧本正文体例（AI 视频体系）

```
## 第 X 集：《集名》（时长：60-90 秒）

### 场景 1｜内景 - 苏家宴会厅 - 夜
【情绪基调：压抑→爆发】【镜头建议：全景开场 → 女主面部特写】

（苏若身穿洗旧的运动服，站在觥筹交错的宴会厅中央。苏雪端着红酒缓步走近。）

苏雪：（轻笑）你也配参加苏家的宴会？门口的保安都比你有身份。

苏若：（平静地看着她，没有躲闪）你说完了？

（全场安静。苏若从口袋里取出一枚印章，放在桌上。特写：苏氏集团继承人社。）

【音效：酒杯碎裂声】【悬念切断：苏雪瞳孔骤缩，画面黑】

▶ 下集钩子：印章真伪验证现场，苏父的手开始颤抖……
```

### 体例硬规则
1. 场景标题格式固定：`内景/外景 - 地点 - 日/夜`，一场戏 1-2 个主要场景；
2. 角色首次出场必须附「角色卡」：年龄/服装/发型/面部特征/年龄感（锁定 AI 视频角色一致性），例：（林峰，25 岁，短发，黑色卫衣，面容普通但眼神锐利）；
3. 台词短句≤20 字/句，每句推进剧情或揭示人物，禁止长独白；
4. 表演/镜头提示放（）内；音效/特效放【】内；
5. 每集结尾必须有「▶ 下集钩子」，明确到最后一个画面；
6. 动作描写具体可拍：不写「他很生气」，写「他把杯子摔在桌上，走向门口，停下，没有回头」。

## 三、分集大纲模板（每集一行）

```
| 集 | Hook（第一句台词级） | 本集冲突 | 情绪峰值 | 悬念结尾（最后画面） | 悬念类型 |
|---|---|---|---|---|---|
| 1 | 「三年前……」 | 当众羞辱被逐出家门 | 女主冷眼离场 | 印章特写 | 隐藏身份 |
```

节奏锚点（30 集制，可按比例缩放）：第 1 集身份确立+危机爆发 → 第 3 集第一个小高潮 → 第 5 集首次反击 → 第 10 集大反转 → 中段每 5 集一次打脸升级 → 第 25-30 集全面清算。

## 四、AI 视频工具适配参数（小云雀/即梦/可灵通用）

| 参数 | 建议 | 理由 |
|---|---|---|
| 画幅 | 竖屏 9:16 | 抖音/快手/红果标准 |
| 单集时长 | 2-3 分钟（平台 60-90 秒剧情核） | 太短撑不起情节，太长流量成本高 |
| 画风 | 都市→真人写实；末世/玄幻→3D；热血→真人或写实 3D | 匹配题材视觉冲击 |
| 角色描述 | 首次出场一次性锁定全要素 | 全剧本级角色管理防换脸 |
| 内心戏 | 转化为旁白或外显动作 | 纯对白场景生成效果更稳 |

## 五、投稿体系正文体例（真人拍摄/平台投稿）

```
第X集

场景：苏家宴会厅
时间：夜
人物：苏若、苏雪、苏父

△宾客举杯，苏若逆光入场，全场目光压过来。
苏雪：（轻蔑）你也配参加苏家的宴会？
苏若：（平静）你说完了？
△苏若从口袋取出印章，放在桌上。特写：继承人社印。
苏父 os：这枚印章……怎么会。

本集钩子：印章真伪验证现场，苏父的手开始颤抖。
（第X集完）
```

符号：`△` 动作描述 / `os` 内心想法 / `VO` 画外音 / `【闪回】…【闪出】` 回忆。台词单句 ≤15 字，每集场景转换 ≤3 次，单集 ≥500 字。
