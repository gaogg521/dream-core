# 短剧内容合规红线清单（审核安全门）

> 知识截止：2026-09。短剧平台（抖音/快手/红果/微信视频号/海外 ReelShort 等）对剧本内容实行先审后播，触线直接限流/下架/封号。本清单为剧本产出的**一票否决项**。

## 一、绝对红线（拒写，无例外）

1. **政治敏感**：涉政人物/事件影射、损害国家主权与领土完整、历史虚无主义表述；
2. **低俗色情**：性暗示情节、软色情擦边、未成年人恋爱亲密描写；
3. **极端暴力**：血腥细节渲染、虐待过程展示、教唆犯罪手法细节；
4. **违法犯罪美化**：毒品/赌博/诈骗被塑造成爽点或成功路径；
5. **歧视侮辱**：种族/民族/性别/残障歧视性内容；
6. **封建迷信糟粕**：宣扬迷信活动敛财、邪教元素；
7. **真实人物侵权**：在世公众人物被虚构为角色（除非用户确认已获授权且为正面虚构）。

## 二、高风险区（需降敏改写）

| 高危写法 | 降敏替代方案 |
|---|---|
| 婆媳极端虐待（毒打/下毒） | 经济控制/言语羞辱等冷暴力 + 反击成长线 |
| 校园霸凌细节过程 | 侧写 aftermath + 反霸凌反击 |
| 自杀/自残情节 | 改为失踪/意外危机，不展示方法 |
| 医疗诊断细节教槽 | 虚化病名，聚焦人物处境 |
| 真实品牌/机构名 | 虚构名（如「顾氏集团」） |
| 赌债/高利贷追债戏 | 改为商业合同陷阱/家族债务纠纷 |

## 三、审核友好设计（写法加分项）

- 反派结局必有因果报应（法律制裁/众叛亲离），不写逍遥法外；
- 主角反击用智慧与合法手段，私刑复仇需付出代价或有金手指架空语境；
- 家庭伦理剧落点回归和解/成长，不终止于纯粹仇恨；
- 悬念用「信息差」而非「感官刺激」驱动。

## 四、海外平台附加注意（ReelShort/DramaBox）

- 年龄分级意识：内容按 PG-13 以下标准把握亲密与暴力尺度；
- 文化适配：身份反转/复仇/霸总题材全球通用，但需避免特定宗教敏感元素；
- 台词避免中文谐音梗/网络梗直译（翻译后失效）。

## 五、2026 监管新增义务（AI 微短剧专项，一票否决）

> 来源：广电总局 2026-06-25《管理提示（AI微短剧分类分层标准）》（2026-07-01 施行）、《微短剧发展管理办法（征求意见稿）》、2026-01-01 微短剧分类新标准。详见 @references/platform-policy-2026.md。

1. **AI 醒目标识**：AI 生成内容必须设置醒目标识——剧本交付时须在文档头预留「AI 生成标识位」并提示用户按平台要求呈现；
2. **AI 工具溯源材料**：AI 微短剧纳入分类分层审核，创作方需额外提交 AI 工具溯源材料——产出时须在「政策校准注记」中列出本项目拟用工具清单（剧本/画面/配音分别注明）；
3. **分类分层备案**：重点微短剧（≥300 万）与普通微短剧（100-300 万）须报省级以上广电主管部门规划备案与成片审查；其他（<100 万）由平台自审报备，片头须标注备案号；
4. **儿童类专项红线**（2026-01 广电总局管理提示）：遏制「成人化」倾向、纠偏「工具化」倾向、抵制「娱乐化」倾向——涉及未成年人角色时，禁止成人化台词、禁止把儿童当作爽点工具、禁止娱乐化呈现苦难；
5. **动画/漫剧专项**（红果+抖音 2026-04-07 起）：强化整剧立意导向审核，禁止宣扬不良价值观、迷信、低俗色情、画风不适及未成年人负面内容。

**交付模板片段（每份 AI 剧本产出必附）**：

```
【AI 生成标识】本剧本由 AI 辅助生成，上线须按平台要求设置醒目标识。
【工具溯源】剧本生成：本平台（AI短剧剧本技能）｜画面生成：待填｜配音：待填
【备案提示】按投资规模对应分类分层要求办理备案，片头标注备案号。
```
