# 人物塑造 · 台词写作 · 画面描写技法库

> 知识截止 2026-09（2026-09-06 联网核验：短剧剧本写作全指南、投稿 12 项要求、AI 漫剧创作实操帖）

## 一、人物塑造黄金三角

1. **命运弧线**：设 3 个关键转折点（如 第3集被背叛 → 第5集觉醒 → 第8集复仇），弧线必须「被动→主动」转向；
2. **个性化标签**：每个角色 ≥2 个视觉化特征（左耳缺失的杀手 / 永远穿红裙的侦探），让观众 3 秒认人；
3. **群体差异化**：主要角色（≤5 人）形成互补的「能力矩阵」，避免同质工具人堆砌。

### 人物小传模板（3-5 行）

```
【苏若】22岁 / 被弃真千金 / 冷静克制
- 标签：沉默反击型、不哭诉只行动
- 视觉特征：①洗旧运动服 ②右眼下方一颗浅色小痣
- 弧线：隐忍（1-3集）→ 亮证（5集）→ 接管（25-30集）
- 台词风格：短句、反问、留白
```

### 反派设计三原则
- **嚣张但有漏洞**：为后续打脸预埋把柄（如当众说出的谎言被录音）；
- **有自身逻辑**：不是纯工具人，反派的动机要能自洽（增强转折可信度）；
- **蠢度可控**：末世/爽文类可适度降低反派智商以放大打脸对比，都市类反派需有真实威胁力。

## 二、台词三字诀：短 · 狠 · 有情绪

**硬性要求**：单句 ≤15 字（竖屏适配，AI 口型不易错位）；拒绝长句、拒绝文艺腔、拒绝讲道理。

### 三类万能台词模板

| 角色位 | 公式 | 示例 |
|---|---|---|
| 反派 | 嚣张 + 碾压式羞辱 | 「你配吗？你连给我提鞋都不配。」 |
| 主角 | 冷静 + 留白 + 反杀预告 | 「急什么？笑到最后的人还没开口。」 |
| 护短位 | 强势 + 占有欲 + 笃定 | 「我的人，你动一下试试。」 |

### 绝对禁止的台词
- 大段解释背景（用画面/道具交代）
- 角色互相讲道理（观众要情绪解压不是上课）
- 过于书面的句子（"月光洒在她忧伤的脸庞上"在短剧里活不过一秒）

### 台词自检三问
1. 这句删掉剧情还能推进吗？（能 → 删）
2. 这句能不能改成动作？（能 → 改）
3. 这句超过 15 字了吗？（是 → 拆）

## 三、画面描写：只写看得见的

**口诀：只写看得见的，不写心里想的。摄影机拍不到的，不要写进剧本。**

| ❌ 错误写法 | ✅ 正确写法 |
|---|---|
| 阳光明媚，微风轻拂，她心里很难过，想起童年往事 | 她攥紧手指，压下眼底的红，抬头看向众人 |
| 他很生气 | 他把杯子摔在桌上，走向门口，停下，没有回头 |
| 场面很尴尬 | 所有人都低头看手机，没人接她的话 |

**标准动作格式**：动作 + 状态 + 镜头重点。例：众人围上来，目光落在女主身上。女主攥紧手指，压下眼底的委屈，抬头看向众人。

## 四、结尾钩子三选一（没有钩子 = 单集不合格）

1. **反转悬念**：所有人都没想到，她根本不是普通人。
2. **危机悬念**：下一秒，更大的陷阱彻底袭来。
3. **身份悬念**：这时，男人手机弹出顶级家族专属来电。

**节奏模板**：【0:15 冲突爆发】→【1:00 对抗升级】→【1:45 反转打脸】→【结尾留悬念】

## 五、标志性动作符号化（表演 + AI 生成双友好）

| 动作符号 | 含义 | 适用 |
|---|---|---|
| 扯领带 | 动怒/失控 | 霸总/上位者 |
| 握拳发抖 | 隐忍 | 逆袭主角前期 |
| 慢条斯理擦手 | 蔑视/胜券在握 | 反派 |
| 摘下眼镜 | 认真/进入战斗状态 | 智斗型角色 |
| 摔物（杯/协议） | 决裂 | 关系转折点 |

> AI 生成提示：优先微表情与微动作（眨眼、嘴角微动、发丝飘动、转头），避免复杂手势与大张嘴动作（AI 手部/嘴部最易变形）。
