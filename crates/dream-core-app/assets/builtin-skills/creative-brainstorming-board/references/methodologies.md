## 概览
本文档提供结构化思维方法，专用于白板第四栏"方案假设"阶段，帮助生成"不用 X，改用 Y"的创新假设。

## 第一性原理拆解法

### 原理
将复杂问题拆解为最基本的功能本质，从本质出发重新思考解决方案。

### 适用场景
- 第三栏"本质拆解"需要深入时
- 第四栏需要基于本质功能生成假设时
- 传统方案存在明显局限时

### 操作步骤

1. **识别传统方案的核心假设**
   - 传统方案默认了什么？
   - 这些假设是否真的是必需的？

2. **拆解到功能本质**
   - 写出「动词 + 对象」的功能本质
   - 区分必需功能和非必需功能

3. **对每个非必需功能提问**
   - 为什么需要这个功能？
   - 如果去掉它，用什么替代？

4. **生成替代假设**
   - 格式：不用 X（非必需功能），改用 Y（替代方案）

### 示例

**问题**：餐具清洁

**传统方案核心假设**：
- 必须高温消毒
- 必须喷淋清洗
- 必须排水干燥

**功能本质拆解**：
- 去除残渣（必需）
- 去除油脂（必需）
- 抑制细菌（必需）
- 高温（非必需）
- 喷淋（非必需）
- 排水（非必需）

**生成假设**：
- 不用高温，改用化学酶
- 不用喷淋，改用超声波
- 不用排水，改用封闭循环

## 约束倒逼创新法

### 原理
通过严格限制某些条件，迫使思维跳出传统框架，寻找突破性方案。

### 适用场景
- 第二栏"约束边界"非常严格时
- 传统方案违反约束时
- 需要在极端条件下寻找解决方案时

### 操作步骤

1. **列出所有约束条件**
   - 空间约束：20-30L
   - 能源约束：12V、低功率
   - 液体约束：封闭水、无外排
   - 安全约束：行驶中、无蒸汽

2. **识别传统方案违反的约束**
   - 传统洗碗机需要大量水 → 违反液体约束
   - 传统洗碗机需要高温 → 违反能源约束
   - 传统洗碗机体积大 → 违反空间约束

3. **针对每个违反的约束生成假设**
   - 格式：不用违反约束的方法 X，改用满足约束的方法 Y

4. **组合多个约束的解决方案**
   - 找到同时满足多个约束的方案

### 示例

**约束条件**：
- 空间：20-30L
- 液体：封闭水、无外排
- 能源：12V、低功率
- 安全：行驶中、无蒸汽

**传统方案违反点**：
- 需要大量排水 → 违反"封闭水"
- 需要高温 → 违反"低功率"
- 需要稳定放置 → 违反"行驶中"

**生成假设**：
- 不用大量水，改用少量循环水
- 不用高温，改用化学酶 + 时间
- 不用稳定放置，改用防晃设计

## 假设验证法

### 原理
将每个方案假设转化为可验证的命题，通过快速迭代降低风险。

### 适用场景
- 第四栏生成了多个假设时
- 第五栏需要识别关键风险时
- 规划下一版白板迭代时

### 操作步骤

1. **将假设转化为可验证命题**
   - 格式："如果我们采用 [不用 X，改用 Y]，那么应该观察到 [结果]"

2. **识别关键验证点**
   - 哪些假设最不确定？
   - 哪些假设失败会导致整个方案失效？

3. **设计快速验证方法**
   - 最小化测试：用最简单的方式验证假设
   - 定性验证：先定性，再定量

4. **将验证结果反馈到下一版白板**
   - 如果假设成立 → 继续深入
   - 如果假设失败 → 回到第一栏，重新定义问题

### 示例

**假设**：不用高温，改用化学酶 + 时间

**可验证命题**：
- 如果使用化学酶 + 30分钟时间，那么应该达到与高温消毒相同的抑菌效果

**关键验证点**：
- 酶的抑菌效果是否足够？
- 30分钟时间是否可接受？
- 化学残留是否安全？

**验证方法**：
- 实验室测试：对比酶和高温的抑菌效果
- 用户调研：用户是否愿意等待30分钟
- 安全评估：化学残留是否在安全范围内

**迭代方向**：
- 如果效果不够 → 假设失败，回到第一栏，重新定义"抑制细菌"的本质
- 如果效果足够但等待时间太长 → 下一版白板第四栏：不用等待，改用低温物理杀菌

## 类比迁移法

### 原理
借鉴其他领域或场景的解决方案，迁移到当前问题中，生成创新假设。

### 适用场景
- 传统方案已经穷尽时
- 需要跨领域创新时
- 第四栏需要多样化假设时

### 操作步骤

1. **识别问题的本质功能**
   - 从第三栏提取核心功能：去除残渣、抑制细菌、防止腐败

2. **寻找具有相同本质功能的其他领域**
   - 哪些领域也在"去除残渣"？（工业清洗、医疗器械）
   - 哪些领域也在"抑制细菌"？（食品保鲜、医疗消毒）
   - 哪些领域也在"防止腐败"？（冷链运输、真空包装）

3. **分析其他领域的解决方案**
   - 工业清洗用什么？超声波、酶解
   - 食品保鲜用什么？真空、低温、天然抑菌剂
   - 医疗消毒用什么？紫外线、臭氧、等离子体

4. **生成迁移假设**
   - 格式：不用 X（传统方案），改用 Y（其他领域的方案）

### 示例

**问题**：餐具清洁

**本质功能**：去除残渣、抑制细菌、防止腐败

**其他领域借鉴**：

**工业清洗**：
- 超声波清洗
- 酶解清洗
- 干冰清洗

**食品保鲜**：
- 真空包装
- 低温冷藏
- 天然抑菌剂（乳酸菌发酵）

**医疗消毒**：
- 紫外线消毒
- 臭氧消毒
- 等离子体消毒

**生成假设**：
- 不用喷淋，改用超声波
- 不用化学药剂，改用天然抑菌剂（乳酸菌发酵）
- 不用高温，改用紫外线
- 不用水，改用干冰

## 综合应用建议

在白板第四栏应用这些方法时，建议按照以下顺序：

1. **先用第一性原理拆解法**
   - 明确传统方案的核心假设
   - 拆解到功能本质
   - 区分必需和非必需

2. **再用约束倒逼创新法**
   - 列出所有约束
   - 识别违反约束的传统方案
   - 针对性生成替代假设

3. **然后用类比迁移法**
   - 跨领域寻找灵感
   - 借鉴其他领域的解决方案

4. **最后用假设验证法**
   - 将假设转化为可验证命题
   - 识别关键验证点
   - 为下一版白板迭代做准备
