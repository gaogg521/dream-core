# 经验库与高频方案速查（Experience Base）

> 本文件是本技能的「记忆」。**每次开工前先读本文件**，命中同类历史成功方案则优先复用；**每次解决问题后**，用 Edit 在「动态经验记录」追加一条，成功的方案提升优先级、踩雷的方案标记慎用。优先级 = 使用频率 × 成功率，越靠前越优先。

## 一、四大高频需求与最优方案（按实际频率排序）

### 1. 建图（最高频，优先考虑）★
- **定义**：从零生成一张规范、可打开的图纸。
- **最优方案**：`scripts/gen_dxf.py` 直接生成 DXF（不依赖 AutoCAD、结果确定、可反复验证）。
  - 规则机械件 → `plate`（矩形板带孔）
  - 建筑房间平面 → `floorplan`（矩形房间+门洞）
  - 任意图形 → `spec`（JSON 规格，line/circle/arc/rect/polyline/text/dim/block_ref）
  - 空白图框 → `blank`（含国标图框+标题栏）
- **备选**：SCR 脚本（用户要在 AutoCAD 内交互）、AutoLISP（批量/参数化）。
- **关键点**：单位统一 mm；分图层分线型；中文文字用大字体 `gbcbig.shx`，否则显示问号。

### 2. 改图（次高频）
- **定义**：修改/补充已有图纸（加尺寸、改图层、补标注、换图框、增删图形）。
- **最优方案**：用 ezdxf 读入原 DXF → 定位目标实体（按 layer/type/handle）→ 修改或新增 → 另存新文件。
- **备选**：生成 SCR 增量脚本在 AutoCAD 内改。
- **关键点**：**先备份原图**；改完跑一遍 `AUDIT` + `PURGE`；不覆盖原文件，另存新版本。

### 3. 提取（数据复用）
- **定义**：从图纸提取数据——尺寸清单、材料表/BOM、图层清单、文字标注、坐标、块属性。
- **最优方案**：ezdxf 只读遍历 `modelspace`，按实体类型提取字段，输出 CSV / 表格。
- **关键点**：注意 `INSERT`（块引用）及其属性（ATTRIB）需递归展开；标注实体取 `dim` 的测量值而非文字。

### 4. 优化（规范化/瘦身）
- **定义**：把乱图变规范——图层归并、线型统一、颜色 ByLayer、图框标准化、冗余清理。
- **最优方案**：ezdxf 批量改实体/图层的颜色、线型、图层归属；配合 SCR 跑 `LAYTRANS`/`SETBYLAYER`/`PURGE`/`OVERKILL`。
- **关键点**：一切特性优先 `ByLayer`；改前备份；优化后对比图层表确认没洗坏。

## 四、术语速查（教学式解答用）

| 术语 | 大白话解释 |
|------|-----------|
| 图层 Layer | 把图按类型分成一叠「透明纸」，可单独开关、改色、锁定，互不干扰 |
| 线型 Linetype | 线的样式：实线 / 虚线 / 点划线（轴线中心线）/ 双点划线 |
| 线宽 Lineweight | 线的粗细，粗线画轮廓、细线画标注文字 |
| 标注样式 Dimstyle | 尺寸标注的统一格式（箭头大小、文字高度、小数位） |
| 图框 Frame | 图纸最外面的边框 + 右下角标题栏，规定画图范围 |
| 标题栏 Title block | 图框右下角的表格，填图名、图号、比例、设计人、日期 |
| 视口 Viewport | 布局里看模型空间的那个「窗口」，每个窗口可设不同比例 |
| 块 Block | 一组图形打包成一个可反复引用的整体（如门、螺栓、图签） |
| 属性 Attribute | 块里面可以填写的文字字段（如门窗编号、图号） |
| ByLayer | 「跟随图层」——颜色/线型/线宽都听图层的，不单独乱设 |
| 比例 Scale | 图上尺寸和实物尺寸的换算关系（1:100 即图上 1 代表实物 100） |
