# 制图标准参考（国标）

本文档定义本技能绘图时遵循的国标约定，供绘制时直接套用。

## 一、图幅与图框（GB/T 14689）

图纸幅面尺寸（单位 mm，长×宽，长边为 X）：

| 图幅 | 尺寸（宽×高） | 备注 |
|------|---------------|------|
| A0 | 1189 × 841 | |
| A1 | 841 × 594 | |
| A2 | 594 × 420 | |
| A3 | 420 × 297 | |
| A4 | 297 × 210 | |

图框留边（留装订边格式）：

| 图幅 | 装订边 a | 其余边 c |
|------|----------|----------|
| A0、A1 | 25 | 10 |
| A2、A3、A4 | 25 | 5 |

> 默认采用「留装订边」格式（左 25mm，上/下/右 5 或 10mm）。

## 二、标题栏（GB/T 10609.1）

- 标准标题栏尺寸：**180 × 56 mm**（A4 竖放）；位于图框右下角。
- 必填字段：单位名称、图名、图号、比例、材料（机械）、设计/制图/审核签名与日期、图样标记、共 X 张第 X 张。
- 简化标题栏可只保留：图名、图号、比例、设计、日期。

## 三、图线（GB/T 4457.4 / GB/T 17450）

| 线型 | 用途 | 线宽 | 建议颜色 | 图层名 |
|------|------|------|----------|--------|
| 粗实线 | 可见轮廓线、图框 | 0.5~0.7 | 白色/黑色(7) | 粗实线 |
| 细实线 | 尺寸线、剖面线、指引线 | 0.25 | 青色(4) | 细实线 |
| 虚线 | 不可见轮廓线 | 0.35 | 黄色(2) | 虚线 |
| 点划线 | 轴线、中心线、对称线 | 0.25 | 红色(1) | 点划线 |
| 双点划线 | 假想轮廓、极限位置 | 0.25 | 品红(6) | 双点划线 |
| 波浪线/折断线 | 断裂边界 | 0.25 | 青色(4) | 细实线 |

线宽比：粗:中:细 = 4:2:1（常用 0.7 / 0.35 / 0.25）。

## 四、文字与标注（GB/T 14691 / GB/T 4458.4）

- 文字样式：汉字用长仿宋体（AutoCAD 用 `gbcbig.shx` 大字体 + `gbeitc.shx`/`gbenor.shx`）。
- 字高系列：1.8 / 2.5 / 3.5 / 5 / 7 / 10 / 14 / 20 mm。图纸说明常用 3.5 或 5，标题栏图名 7~10。
- 尺寸标注：箭头 3~5mm 长、文字高 3.5、尺寸界线超出尺寸线 2mm、尺寸线间距 7~10mm。
- 角度、直径、半径符号：`°`、`Ø`、`R`（机械）；建筑用 mm，总平面用 m 并在图内注明。

## 五、各行业图层命名建议

| 行业 | 常用图层（示例） |
|------|------------------|
| 机械 | 粗实线、细实线、虚线、点划线、尺寸标注、剖面线、文字 |
| 建筑 | 轴线(点划线)、墙体(粗实线)、门窗、标注、文字、楼梯、家具 |
| 电气 | 强电、弱电、桥架、灯具、插座、标注 |
| 给排水 | 给水管、排水管、消防、立管、标注 |
| 暖通 | 风管、水管、设备、标注 |
| 钢结构 | 构件、螺栓、焊缝、标注 |

> 图层名可中英混合，但同一张图内必须统一；颜色默认按第三节约定。

## 六、比例（GB/T 14690）

- 机械：原值 1:1；放大 2:1、5:1、10:1；缩小 1:2、1:5、1:10。
- 建筑：常用 1:100、1:50、1:20（详图）；总平面 1:500、1:1000。

## 七、行业相关标准号速查

- 机械制图：GB/T 4457~4459、GB/T 14689~14692。
- 建筑制图：GB/T 50001、GB/T 50103~50106、GB/T 50114。
- 电气制图：GB/T 6988（电气技术用文件的编制）、GB/T 18135、GB/T 4728（图形符号）。
- 工艺/管道：GB/T 50184、HG/T 20519（化工 PID）。
- 钢结构：GB/T 50105、GB/T 50205。
