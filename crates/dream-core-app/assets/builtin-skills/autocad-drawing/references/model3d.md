# 转可旋转 3D 模型（model3d.cjs）

把 CAD 文件转成**一个独立的 .html 文件**：浏览器或本平台的预览面板里直接打开，鼠标拖动旋转、滚轮缩放、右键平移，**完全离线**（three.js 与 OpenCascade 都随技能自带，不访问任何 CDN）。只需要 Node 18+，不用装 Python 或 pip 包。

## 命令

```bash
# 3D 图纸 / 模型 -> 可旋转 3D（默认输出到输入文件旁边的 <名字>.3d.html）
node scripts/model3d.cjs view 输入文件 --out 结果.3d.html --title "图名"

# 二维/三维型线图 -> 船体曲面
node scripts/model3d.cjs loft 型线图.dxf --out 船体.3d.html
node scripts/model3d.cjs loft 型值.json  --out 船体.3d.html

# 只看会显示什么（零件/图层、三角面数、包围盒、警告），不生成 HTML
node scripts/model3d.cjs info 输入文件
```

通用参数：`--unit mm|m|in`（图纸头里单位写错时手动指定）、`--lang zh|en`、`--up z|y`（模型躺倒了就换）、`--quality low|medium|high`（仅 STEP/IGES，面数过多时用 low）、`--encoding gbk`（老 DXF 中文乱码时）。

## 支持的输入

| 输入 | 能显示什么 | 注意 |
|------|-----------|------|
| **DXF 三维线框** | LINE、3D 多段线、样条、圆弧等，保留图层和颜色 | 只有线没有面，就是线框显示 |
| **DXF 三维面/网格** | 3DFACE、多面网格（PFACE）、M×N 网格、MESH、SOLID | 按图层分组着色 |
| **DXF 带厚度的二维图元** | 有 thickness 的线、多段线、圆会拉伸成墙/柱 | 建筑「2.5D」模型常见 |
| **DXF 块** | INSERT（含旋转、缩放、倾斜的 OCS、阵列 MINSERT），嵌套块 | 0 层图元随块所在图层 |
| **STEP / STP / IGES / IGS / BREP** | 真实体，按零件分组、带颜色 | 装配体几十个零件约 1 秒 |
| **STL**（二进制/ASCII）、**OBJ** | 网格模型 | OBJ 默认按 Y 轴朝上 |
| **型线图 DXF / JSON** | 用 `loft` 放样成船体曲面（左右舷镜像），叠加横剖线和纵向参考线 | 见下文约定 |

**不支持，并会给出原因：**

- **DWG**：Autodesk 私有格式。在 AutoCAD/中望/浩辰里「另存为 DXF」即可。
- **SolidWorks（.sldprt/.sldasm）、Inventor、CATIA、NX/Creo（.prt）、Solid Edge、Parasolid、SketchUp、Rhino 等原生格式**：没有公开规范，任何开源库都读不了，**不要尝试逆向解析二进制**（白费时间且不会有结果）。请用户在原软件里「另存为 / 导出」STEP（首选，保留零件和颜色）或 STL；文件是别人发来的，就请对方导出 STEP。工具遇到这些扩展名会直接给出这条提示。
- **DXF 里的 3DSOLID/REGION/曲面（ACIS 实体）**：几何是加密的 ACIS 数据，读不出来。在 AutoCAD 里用 `EXPORT` 导出 STEP，或 `STLOUT` 导出 STL，再转换。
- **纯二维平面图**（所有 Z 都相同）：没有高度信息，转出来是平的。工具会给出提示。二维平/立面要建模，得先补充高度（例如给墙线设置 thickness）。
- **二进制 DXF**：另存为 ASCII DXF。

## 型线图放样约定（loft）

工具会自动识别两种画法：

1. **三维型线**（Rhino、Maxsurf 等导出）：每条横剖线是一条落在 `x = 常数` 平面里的 3D 曲线。工具自动按 x 分站。不在站位平面上的线（水线、纵剖线）会作为参考线一起显示。
2. **二维横剖面图**（body plan）：横剖线画在 Y–Z 视图里，**站位 x 坐标写在图层名末尾**，例如 `ST_1500`、`站-3000`。
   - 图层名里写的是站号而不是坐标，就加 `--station-scale 站距`（站号×站距 = x）。
   - 中线不在 0 时加 `--centerline 中线横坐标`。左半边画艉部、右半边画艏部的画法会自动取绝对值。
   - 只用部分图层时加 `--layers "^ST"`（正则）。

一个站位被画成好几段时，会按端点自动拼接。拼不上会警告：「断成 N 段，已按最长一段放样」。

JSON 型值格式（单位与坐标一致，`points` 从龙骨到甲板边线排列，y 取半宽）：

```json
{ "unit": "mm", "mirror": true,
  "stations": [ { "x": 0, "points": [[0,0],[800,500],[1200,1500]] },
                { "x": 6000, "points": [[0,0],[2400,500],[4800,3500]] } ] }
```

**精度说明**：曲面由相邻横剖线按弧长一一对应插值，适合看外形、做汇报和检查型线是否顺。它**不能替代**光顺后的型值表，也不能用于静水力计算。工具每次都会在页面左下角写上这句提醒。

## 查看器功能

- 视图：适应 / 前 / 后 / 左 / 右 / 顶 / 底 / 轴测，透视与正交切换
- 显示：实体、线框、边线（特征边）开关
- 图层/零件：逐个勾选显示或隐藏
- 剖切：X/Y/Z 方向剖切面，可拖动位置、反向
- 截图：导出当前画面为 PNG
- 双击模型表面：把旋转中心移到该点
- 左下角：包围盒尺寸 + 单位、零件数、面数，以及所有警告

## 交付时说明

1. 告诉用户输出的 `.3d.html` 路径，提示在预览面板打开即可旋转查看。
2. 原样转述 `WARN` 行（单位可疑、ACIS 实体读不出、纯平面图、放样精度等），不要省略。
3. 超过 30MB 的输出打开会慢：STEP 加 `--quality low` 重新生成。
