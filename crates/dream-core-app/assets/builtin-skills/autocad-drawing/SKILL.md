# AutoCAD 图纸绘制（自进化版）

## 用途

为各类行业生成/修改规范、可直接用 AutoCAD 打开的图纸，并从图纸提取数据、优化规范化。默认输出 **DXF 文件**（AutoCAD 可直接打开另存为 DWG），需要交互式绘图时输出 **SCR 脚本**或 **AutoLISP(.lsp)** 供用户在 AutoCAD 内运行。

## 核心进化机制（v1.1，最重要的能力）

本技能不是一次性的工具，而是「越用越聪明、越用越顺手」的助手。每次执行都遵守以下五条铁律：

### 1. 经验优先（先查记忆，再动手）
- 开工前**必先读** `@references/experience-base.md`，看「动态经验记录」里有没有同类问题已成功的方案。
- 命中 → 直接复用该方案，不重新推理、不重复造轮子。
- 没命中 → 查「高频需求方案速查」，命中四大高频需求（建图/改图/提取/优化）直接套用预置最优解。
- 都没有 → 才走通用推理。

### 2. 用后沉淀（每次解决完，写回记忆）
- 每解决一个问题，用 Edit 在 `references/experience-base.md` 的「动态经验记录」追加一条：`需求类型 / 采用方案 / 结果 / 经验`。
- 成功 → 记为成功，同类问题下次优先采用；失败/踩雷 → 记「慎用」并写明踩了什么雷，下次规避。
- 这是「越用越聪明」的物理基础，**不可省略**。

### 3. 教学式解答（新手也秒懂）
- 每次输出分两层：先给「直接能用的结果」，再给「讲解」——这一步为什么这么做、关键命令/术语用大白话解释。
- 对 CAD 常用功能与专业词汇（图层、线型、线宽、标注样式、图框、标题栏、视口、块、属性、比例等），见经验库「术语速查」表，适当穿插讲解，别默认用户都懂。

### 4. 主动优化建议（还能更好就说）
- 交付时，若存在「更省事 / 更规范 / 更不易返工」的现成更好办法，且确定不翻车、不踩雷、不浪费用户时间，用「💡 还能更好」的形式顺带提出，不强迫、不啰嗦。

### 5. 培养默契（越用越离不开）
- 交付末尾用一句「下次你直接说『画个 XXX』我就照这个套路最快出图」，引导用户用最小输入拿到最快结果。

## 触发场景

- **建图**：用户要求「画个 XXX 图」「做个机械零件图 / 建筑平面图 / 电气原理图 / 工艺流程图 / 户型图 / 钢结构详图」等。
- **改图**：用户要求「这张图加个尺寸 / 换个图层 / 补个标注 / 换个图框 / 改一下比例」。
- **提取**：用户要求「把图里的尺寸/材料表/图层/文字/坐标 导出来」。
- **优化**：用户要求「这图图层很乱，帮我规范一下 / 清理一下 / 统一线型」。
- 用户提到 AutoCAD / CAD / DWG / DXF / 出图 / 图框 / 标题栏 / 三视图 / 轴测图 / 标注 / 图层 / 线型。
- 需要生成规范的图纸文件交给设计、生产、报审、备案（如软著附图、专利申请附图、工程图纸）。

## 高频需求方案速查

| 需求 | 最优方案 | 说明 |
|------|----------|------|
| **建图** | `scripts/gen_dxf.py`（DXF 生成） | plate / floorplan / spec / blank 四种子命令 |
| **改图** | ezdxf 读入定位修改后另存 | 先备份原图，改后 AUDIT+PURGE |
| **提取** | ezdxf 只读遍历实体导出 CSV | 注意块引用与属性递归展开 |
| **优化** | ezdxf 批量改 + SCR 跑 LAYTRANS/PURGE | 特性一律 ByLayer，改前备份 |

详细方案、参数与动态经验见 `@references/experience-base.md`。

## 工作流程

### 第 0 步：查经验库（每次必做）

读 `@references/experience-base.md`，命中同类成功方案则直接复用，进入第 4 步交付；未命中则继续。

### 第 1 步：明确图纸需求

确认以下要素，缺一不可：

1. **操作类型**（建图 / 改图 / 提取 / 优化）。
2. **行业与图纸类型**（机械/建筑/电气/…，及具体图种）。
3. **关键尺寸与参数**（零件尺寸、房间开间进深、元件清单等）。
4. **图幅**（A0~A4，默认 A4；不确定时按内容大小估算并说明）。
5. **比例**（默认 1:1 机械、1:100 建筑，可后调）。
6. **输出格式**（默认 DXF，可选 DWG 需用户在 AutoCAD 内另存）。

若用户未给全关键尺寸，先列出「还缺哪些尺寸」再动手，避免生成废图。

### 第 2 步：选择生成方式

| 方式 | 适用场景 | 产物 |
|------|----------|------|
| **DXF 生成（推荐）** | 建图/改图/提取，有明确参数，可程序化处理 | `.dxf` / 数据文件 |
| SCR 脚本 | 用户在已打开的 AutoCAD 里交互绘图/改图 | `.scr` 文件，`SCRIPT` 命令运行 |
| AutoLISP | 参数化/批量/重复出图 | `.lsp` 文件，`APPLOAD` 加载后调用 |

优先用 DXF 生成，因为它不依赖 AutoCAD 运行、结果确定、可反复验证。

### 第 3 步：生成 / 处理图纸（DXF 方式）

使用 `scripts/gen_dxf.py`：

```bash
# 依赖：ezdxf（首次使用自动提示，见脚本头部）
python scripts/gen_dxf.py --help

# 生成空白图纸（含国标图框 + 标题栏）
python scripts/gen_dxf.py blank --size A3 --out 图纸_A3.dxf

# 从 JSON 规格文件生成任意图形
python scripts/gen_dxf.py spec --json drawing.json --out 结果.dxf

# 机械矩形板（带孔、中心线）
python scripts/gen_dxf.py plate --w 100 --h 60 --holes "20,20;80,40" --out 板件.dxf

# 简单建筑平面（矩形房间，含门洞示意）
python scripts/gen_dxf.py floorplan --json floorplan.json --out 户型.dxf
```

运行脚本的依赖安装（隔离环境）：

```bash
python -m venv .venv
.venv/Scripts/pip.exe install ezdxf
.venv/Scripts/python.exe scripts/gen_dxf.py ...
```

JSON 规格字段与示例见 `@references/dxf-notes.md` 与 `templates/` 目录。

### 第 4 步：交付（含教学 + 建议 + 沉淀）

1. 把生成的 `.dxf`（或数据文件）放到工作目录，用 本平台 呈现给用户。
2. 说明：图幅、比例、图层、用了哪些国标规范。
3. **教学式讲解**：用一两句话讲清「这一步为什么这样做」，关键术语附大白话解释。
4. **主动优化建议**：若有更省事/更规范的现成办法，用「💡 还能更好」附带提出。
5. **经验沉淀**：用 Edit 把本次「需求/方案/结果/经验」追加到 `references/experience-base.md` 的动态经验记录。
6. **培养默契**：结尾一句「下次直接说 XX 最快」。
7. 如需 DWG，提示用户在 AutoCAD 里「另存为」即可；如需批量/参数化，补 AutoLISP 脚本。

## 关键约束

- **单位统一 mm**（建筑总平面可用 m，需在图框注明）。
- **图层规范**：粗实线、细实线、虚线、点划线、双点划线、标注、文字、图框，分图层绘制，颜色按国标。
- **中文文字**：DXF 文字样式启用大字体 `gbcbig.shx`，否则中文显示为问号。
- **不虚构尺寸**：用户没给的尺寸，用占位并在交付说明中标注「待确认」。
- **图纸合规**：涉及地图/地形图时，先触发地图合规技能检查中国版图规范。
- **改图/优化前先备份**：绝不覆盖原图，一律另存新版本。
