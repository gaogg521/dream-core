# 会议跟进闭环规范

## 一、跟进节奏

- 会中：记录待办。
- 会前：核对上次待办。
- 会后：当日发出纪要 + 待办提醒。

## 二、状态标记

| 状态 | 含义 | 动作 |
|---|---|---|
| ✅ 已完成 | 满足验收标准 | 记录完成时间 |
| 🔄 进行中 | 有进展未完成 | 更新进度 |
| ⚠️ 逾期 | 超期未完成 | 归因 + 催办 |
| ⛔ 阻塞 | 有依赖问题 | 明确卡点与升级路径 |

## 三、逾期归因框架

- 没有时间节点 → 补设时间。
- 没有负责人 → 明确责任人。
- 依赖阻塞 → 上报协调或调整范围。
- 优先级下降 → 显式取消或降级，不默许拖延。

## 四、催办话术模板

```
您好，@负责人，事项「XX」约定【日期】完成，目前进度【状态】。
是否需要协调资源？若本期无法完成，请明确新的时间点。
```

## 五、周会复盘

- 上周闭环率 = 按时完成数 / 待办总数。
- 连续两周 <80% 的项目，提示评估范围与人力。
