# 会议纪要结构化规范

## 一、纪要骨架

```
会议信息：主题 / 时间 / 参会人 / 主持人
一、议题回顾（上次遗留）
二、各议题
  议题 N：讨论要点 → 结论/决策
三、待办清单（人 + 时间 + 优先级）
四、风险与未决事项
```

## 二、三类信息区分

| 类型 | 定义 | 处理 |
|---|---|---|
| 决策 | 已拍板的事 | 记录结论 + 理由，避免会后反复 |
| 待办 | 需要有人做的事 | 提取为行动项 |
| 信息同步 | 只需知晓 | 简要记录，不进待办 |

## 三、写作要求

- 忠实原意，不加个人评价。
- 争议点客观记录各方立场。
- 口语转书面：去口头禅、补主语、合并重复。
- 每条待办必须有「人 + 时间」，否则标注「待确认」。

## 四、避免

- 把纪要写成逐字稿（过长）。
- 遗漏决策（重点核对拍板内容）。
- 含糊表述（用「尽快」不用「尽快」，要具体到日期）。
