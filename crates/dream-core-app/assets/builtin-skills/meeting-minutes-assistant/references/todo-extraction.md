# 待办提取规范

## 一、提取信号词

- 动作类：「需要做」「要跟进」「负责」「推动」「确认」「落地」
- 责任类：「谁去」「你来」「我安排」
- 时间类：「本周」「月底」「下周一」「XX 前」

## 二、待办五要素

| 要素 | 说明 | 缺失处理 |
|---|---|---|
| 事项 | 做什么（动词开头） | 必填 |
| 负责人 | 谁来做 | 缺→标「待确认」 |
| 截止时间 | 何时完成 | 缺→向用户询问 |
| 优先级 | 高/中/低 | 按影响与紧急性判断，可让用户确认 |
| 验收标准 | 做到什么程度算完成 | 尽量补全 |

## 三、写法示例

- ❌ 「跟进一下项目」
- ✅ 「周三 18:00 前，张三整理项目排期表并发群，验收：包含三个里程碑时间点」

## 四、拆分原则

- 一个大任务拆成可独立完成的子任务。
- 超过一周的长任务标注里程碑节点。
