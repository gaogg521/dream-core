# 文献报告模板规格（写死，逐字节遵循）

基准：与「文献报告」标准模板同源（hero / stats / 文章清单 / 卡片 / 筛选栏 / JS 渲染）。
样式：`<style>` 从 `scripts/report-style.css` **逐字节复制**，禁改任何选择器、变量、字号。

## 1. 页面骨架（顺序写死）

```
<!DOCTYPE html> → <html lang="zh-CN"> → <head>(meta charset/viewport + <title> + <style>母版</style>) → <body>
<div class="wrap">
  ① <header class="hero"> — h1：{客户主题}文献报告
                           .sub：检索式｜时间窗（全角｜分隔）
                           .meta：数据来源 PubMed（NCBI E-utilities）｜数据截至 {年-月}｜IF 来源 JCR2025
  ② <div class="stats">   — 文献总数 / 研究论文 / 综述 / 含影响因子篇数（4 卡）
  ③ <div class="sec">     — <h2>文章清单（共 N 篇）</h2> + .bar 筛选栏 + <div id="list">（JS 渲染 .card）
  ④ <div class="ok">      — 通讯作者口径说明（末位作者及其单位；aff_src 标记回退规则）
</div>
<script> const DATA=[…] + esc/P/card/apply/初始化 </script>
```

## 2. DATA 字段（写死）

`pmid, year, title, zh, journal, journal_full, journal_canon, ifv, ifq, ptype, authors, corr, aff, aff_zh, doi`

- `zh`：标题中文翻译，**≥95% 篇目必须有**且含中文；期刊名/专业缩写可保留英文。
- `journal`：ISO 缩写（显示用）；`journal_canon`：脚本输出的 JCR 查表规范名（大写、去地名括号、去 The、句点转空格），**IF 查表唯一依据**，精确命中 `scripts/journal_if_map.json`。
- `ifv/ifq`：仅来自 IF 表（`if` + `jcr_quartile`）；**未收录期刊不显示指标，绝不编造**（预印本如 bioRxiv 天然无 IF）。禁用 OpenAlex/IF≈/影响因子约 等估算表述。**口径红线：报告 hero/说明必须写明「IF 为 JCR2025 年度值，非文章发表当年 IF」**。
- `authors`：作者全名，禁 `et al.`；通讯作者条目加 `__CORR__` 前缀（渲染为 `<span class="me">` 高亮）。客户指定追踪作者时用 `__ME__` 前缀。
- `corr/aff/aff_zh`：通讯作者姓名 / 单位原文 / 单位中译。`aff` 取末位作者名下全部 AffiliationInfo（唯一作者取本人；末位缺单位回退首位并说明）；单条 `aff` 通常 ≤400 字符。
- `ptype`：研究 / 综述 / 其他（徽章：紫 / 绿 / 蓝，`font-weight:700`）。

## 3. 卡片 DOM 顺序（写死）

徽章行(年份 b-first + 类型 + IF if-badge) → h3 英文标题 → .zh 中文翻译 → .jmeta 期刊｜PMID 链接｜DOI 链接 → .authors 作者（通讯高亮）→ .aff 通讯作者单位（中译 + `<span class="aff-en">（原文）</span>`）。

## 4. 筛选栏与交互（写死）

- `.bar`：`input#kw`（搜索标题/期刊/作者）+ `select#fyear`（按 DATA 动态填充）+ `select#ftype`（全部类型/仅研究/仅综述/其他）+ `select#sort`（年份降序默认/升序/标题）。
- `apply()`：kw 匹配 title/zh/journal/authors/aff/aff_zh；空结果 `<div class="empty">没有符合条件的文章</div>`。
- PMID 链接：`https://pubmed.ncbi.nlm.nih.gov/{pmid}/`；DOI 链接：`https://doi.org/{doi}`（均 `target="_blank" rel="noopener"`）。

## 5. 铁律

1. DATA 篇数 = h2 标注篇数 = 实际检索篇数，三处一致。
2. 时间窗客户必填；客户给的检索限制（文献类型/语言/排序）如实转成 PubMed 语法，不得私自放宽。
3. 翻译 ≥95%；未收录期刊不显示 IF；作者全名禁 et al.。
4. 正文用词过验证器净化词表（禁 综上所述/此外/总体而言/约…篇 等）。
