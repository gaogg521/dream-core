# 文档格式化排版（gongwen-format）安装说明

**版本**：v2.0.0 ｜ **作者**：胡立敏 ｜ **类型**：本平台 技能（Skill）

一个把 Word 或 Markdown 文档一键排版为符合党政机关公文国标（GB/T 9704-2012 / GB/T 33476.2-2016）的 本平台 技能：字体字号行距标题自动合规、表格美化（表头黑体/数据仿宋/居中）、图片防裁剪处理、图题表题规整、大纲级别导航层级树。**只改格式，不改正文内容。**

---

## 二、安装方法（三选一）

### 方法 1：本平台 界面导入（推荐）

1. 打开 本平台 → 技能管理（技能中心）
2. 选择「导入 / 从文件夹安装」，选中解压后的 `gongwen-format` 文件夹
3. 安装完成后，在技能列表确认显示中文名「文档格式化排版」

### 方法 2：手动复制（迁移到新电脑）

把整个 `gongwen-format` 文件夹复制到目标机器的技能目录：

```
Windows:  C:\Users\<用户名>\.dream\skills\gongwen-format\
macOS:    ~/.dream/skills/gongwen-format/
```

然后**重启 本平台**（技能列表在启动时扫描，中途新增需要刷新）。

### 方法 3：对话内安装

在 本平台 对话里说：「帮我把这个文件夹安装为技能」，Agent 会按规范完成安装与校验。

## 三、运行依赖（一次性准备）

技能的排版引擎依赖 Python + python-docx：

| 依赖 | 要求 | 安装 |
|---|---|---|
| Python | ≥ 3.10 | 官网安装或用 本平台 内置 Python |
| python-docx | 任意近期版本 | `pip install python-docx`（推荐装入独立 venv）|

推荐建独立虚拟环境（不污染系统 Python）：

```bash
python -m venv "%USERPROFILE%\.dream\binaries\python\envs\gongwen-check"
"%USERPROFILE%\.dream\binaries\python\envs\gongwen-check\Scripts\pip.exe" install python-docx
```

> 排版时 Agent 会自动寻找可用的 Python；无环境时会提示安装。字体（仿宋/黑体/楷体/方正小标宋）由 Word/WPS 在缺字体时自动回退，无需额外安装。

## 六、已知边界（使用前知悉）

1. 不自动改正文页脚页码（避免破坏原页脚域）；页码国标为 4 号宋体、`— 1 —` 一字线、单页右/双页左，需在 Word 手工设置（自动化版本规划中）
2. 不探测印章是否加盖，只调整落款日期右空字数
3. 信函/命令/纪要等特定格式公文的专属版式暂不支持
4. Markdown 图片需本地文件路径；Word 原有页眉/页脚内容不会被改动
