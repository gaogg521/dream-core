# 视频转 PPT · 使用与调参说明

> 工具源码 `scripts/video2ppt.py`（单文件 606 行）。本文件供 AI 查阅参数含义与调参策略，也可转述给用户。

## 一、工具能力

把录制的 PPT 演示视频自动切页、抽帧、画质增强，导出成「每页一张图铺满」的图片型 PPTX。

**核心流程**：按采样间隔抽帧 → 相邻帧差异检测（dhash + 像素均值双判据）判断翻页 → 每页选代表帧 → 画质增强链 → 合并相邻相似页 → 导出 PPTX。

**重要边界**：产物是**图片型** PPT，每页是一张图，不做 OCR、不还原可编辑文字。用户若需要可编辑文本，需另做 OCR 或人工录入。

## 二、画质处理链（enhance 函数）

对每页代表帧依次执行：

```
去黑边(letterbox/pillarbox) → 白底干净化(灰度>248 拉回纯白，去灰底噪点)
→ 轻量对比度(CLAHE clipLimit=1.3) → 极轻降噪 → 文字锐化(amount=0.3, sigma=0.5)
→ 按档位限宽(1920)/编码(JPEG 或 PNG)
```

**不做全局白平衡**：早期版本做白平衡会把 PPT 背景和图表搞偏色，已移除。若用户抱怨偏色，不要建议加白平衡。

## 三、参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| `视频路径` | 必填 | 支持 mp4/mkv/avi/wmv 等 cv2 能解的格式 |
| `--out 目录` | 视频同级 `_ppt/` | 输出目录 |
| `--quality` | `lossless` | 画质档位，见下表 |
| `--sample 秒` | 0.3 | 切页采样间隔，越小越精细越慢 |
| `--thresh 数字` | 12 | 切页灵敏度，越小越容易把动画误判为翻页 |
| `--dedup` / `--no-dedup` | 开 | 合并相邻高度相似页（演讲者回翻、动画抖动） |
| `--keep-png` | 关 | 额外导出每页 PNG 原图 |
| `--keep-html` | 关 | 额外导出便携 HTML 放映件（图片内嵌，零依赖） |
| `--selftest` | — | 内置自测（造 3 页测试视频跑通全流程） |

### 画质档位（--quality）

| 档位 | 实现 | 62 页 / 1080p 体积 | 适用 |
|---|---|---|---|
| `lossless`（默认） | PNG 无损 + 限宽 1920 | 约 55MB | 最在意清晰度 |
| `high` | JPEG 98 + 限宽 1920 | 约 30MB | 清晰与体积折中 |
| `compress` | JPEG 92 + 限宽 1920 | 约 25MB | 微信/邮件传输 |
| `full` | PNG 原分辨率 | 最大 | 需原生尺寸做后期处理 |

## 四、调参指南（按症状开药）

| 症状 | 原因 | 怎么调 |
|---|---|---|
| **漏页**（两页内容被合成一页） | 采样太粗，翻页瞬间没采到 | 减小 `--sample`（0.3 → 0.15） |
| **多页**（动画/光标被当成翻页） | 灵敏度过高 | 增大 `--thresh`（12 → 20~30） |
| **演讲者回翻产生重复页** | 去重未生效 | 确认 `--dedup` 开启（默认开） |
| **产物太大** | 默认 lossless PNG | 改 `--quality compress` 或 `high` |
| **文字发虚有白边（halo）** | 锐化过度 | 改 `sharpen()` 的 `amount`（当前 0.3，往下调） |
| **背景/图表偏色** | 早期版本白平衡问题，当前版已移除 | 确认用的是当前版源码，不要自行加白平衡 |
| **要单独拿每页图片** | 默认只出 PPTX | 加 `--keep-png` |
| **要零依赖分享放映** | — | 加 `--keep-html`（图片内嵌，双击即放） |

## 五、性能与已知坑

1. **切页用 `cap.grab()` 跳帧采样**（约 270fps 解码），内存占用极低，1GB / 50 分钟视频约 5~7 分钟，不会 OOM。
2. **纯色页检测**：dhash 对接近纯色的画面会退化，已加「相邻采样帧像素均值差」双判据兜底；极端纯色页仍可能漏判。
3. **时间戳水印**：录屏软件叠加的「00:07」类时间戳默认保留（不在画面主体区域）；如需去除，改 `enhance()` 增加局部修复。
4. **产物体积大是正常的**：62 页 1080p PNG 约 55MB，属预期。
5. **GUI 为可选**：无 tkinter 环境下双击会弹原生提示框，改用命令行即可。

## 六、修改源码指引

| 想改什么 | 找哪个函数 |
|---|---|
| 切页灵敏度 / 合并规则 | `scene_detect()`（pix_thresh、min_dur、thresh） |
| 画质处理链 | `enhance()`（增删锐化 / 对比度 / 白底步骤） |
| 相邻相似页合并 | `run_pipeline()` 的 dedup 段（dedup_thresh=5.0） |
| 压缩档位 / 图片格式 | `run_pipeline()` 的 `quality_cfg` |
| 翻页代表帧选取 | `pick_representative()` |
| 界面文案 | `_no_gui_fallback()` / `gui_main()` |

## 七、打包成独立 exe（可选）

用户若要分发给没装 Python 的人，可在本机重打包：

```bat
pip install -r scripts/requirements.txt
pyinstaller --onefile --windowed --name "视频转PPT" ^
  --hidden-import cv2 --hidden-import numpy --hidden-import PIL --hidden-import pptx ^
  video2ppt.py
```

两个坑：
1. PyInstaller 覆盖旧 exe 可能因文件占用失败，先删或重命名旧 exe 再打包。
2. `--windowed` 打包后命令行中文会乱码，需在 `__main__` 对 stdout/stderr 做 `reconfigure(encoding="utf-8", errors="replace")`（当前源码 v3.1 已修）。

打包后跑 `视频转PPT.exe --selftest`，输出 `SELFTEST OK pages=3 pptx=True` 即通过。

> 注：原工具包 `E:\workbuddy成品存档\视频转PPT\视频转PPT\dist\视频转PPT.exe`（约 76MB）是已打包好的成品，因体积过大未纳入本 skill，需要时从该目录取用。
